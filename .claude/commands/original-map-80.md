# 원본 맵 + 실제 80명 동시 캐릭터 구현
먼저 AGENTS.md와 docs/ORIGINAL_MAP_80_PLAYERS.md, docs/REALTIME_80_ACCEPTANCE.json을 읽는다.
최신 main에서 시작하고 PR #7/#8의 상태를 확인한다. 독서 홈페이지는 수정하지 않는다.
이 문서는 계획이다. 기존 40명 제한을 80으로 바꾸는 것만으로 완료하지 않는다.
원본 HTML 외형 복원 → Cloudflare DO relay + transport adapter → 80-body LOD → staging 실제 WS/실기기 시험 순으로 구현한다.
같은 장면에서 자기 1+상대 79명의 인형을 표시한다. NPC/분방/접속 숫자로 대체하지 않는다.
실제 배포 권한이 없으면 로컬 구현·테스트·설정 예시까지 완료하고 배포/80명 실증은 NOT RUN으로 기록한다.
무료 운영 한도와 실패/지연을 계측하고 자동 결제하지 않는다. 기존 공유 데이터와 롤백 경로를 유지한다.
결과 보고서는 PASS/FAIL/NOT RUN을 구별하고 실제 실행 증거를 남긴다. PR 본문은 사용자 요청대로 "검증 못 했음"만 적고 상세 내용은 저장소 문서에 쓴다.
