# 편한 제작·참배와 현장 방명록

기준 main c70de12. PR39가 병합되어 최신 main 위에서 후속 브랜치 하나로 작업한다. 사용자가 승인한 전체 흐름과 추가 방명록 요청을 구현한다.

## 변경

- 제작 순서는 골조→전기→한지→채색이다. 작업대의 실제 표지/소품, 안내 번호, 목표, 제작 gate, HUD가 같은 순서다. 골조/한지/채색은 선택 후 한 번 확인한다. 전기는 연결 시험 후 다음 단계로 이동하며 소원·최종 점등 미리보기는 채색 뒤다.
- 저장에 craftVersion2를 기록한다. 기존 한지/채색 작업 중인 등은 전기부터 보충하되 이미 완료한 한지/채색은 보존하고 건너뛴다. 완성된 등과 공유 저장 형식은 유지한다. 공용 제작을 쓰는 다른 미리보기의 저장/배치도 같은 순서로 맞춘다.
- 작업장에서는 현재 단계로 이동하는 버튼, 전체에서는 상단 안내 버튼으로 다음 작업대·구정탑·동상·법당·방명록을 선택한다. 실제 보행 충돌을 확인하는 경로를 따라 걷는다. 도착한 뒤 해당 선택창을 열며 원격 제작/참배는 하지 않는다. 수동 이동·중단·창 열기·이탈 시 안내 보행을 취소한다.
- 자동 탑돌이는 한 바퀴 기본이다. 마지막 30% 구간에서 한 바퀴 더를 선택할 수 있고 언제든 멈춘다. 끝나면 완료 모달 대신 짧은 안내를 띄운다. 카메라는 탑 중심의 안정된 구도로 잡는다. 기존 실제 이동각 검증/막힘 중단은 유지한다.
- 법당에서는 빈 방석을 선택해 자동 이동하고 도착 후 절하기 선택창을 연다. 직접 참배를 선택해야 시작한다. 다른 법우가 있는 방석은 선택할 수 없고 도중 점유가 바뀌면 중단한다. 자동 걷기의 실제 속도를 기존 presence에 전달한다. 기존 문턱 입장/퇴장·수동 이동·절 횟수 선택은 유지한다.
- 방명록 저장 기능은 이미 있었다. 작업장 남문 서쪽 옆에 실제 게시판과 근접 행동을 추가하고 상단 메뉴 접근을 유지한다. 기존 public.posts API/삭제 비밀번호/초안 보존을 사용한다. 게시글마다 time 요소로 한국시간 `2026.11.11 10:05`처럼 날짜와 시각을 표시하며 잘못되거나 없는 값은 작성 시각 없음으로 표시한다. 날짜를 새로 만들어 과거 글을 바꾸지 않는다.

## 검증 및 한계

테스트123개 통과, 빌드 통과. 기존 Three.js 번들 크기 경고 유지. 장애물 우회/목적지 차단/취소·도착 속도/구버전 제작/한국시간 변환과 기존 초안·중복 전송 테스트 포함.

독립 코드 리뷰에서 구버전 완료 작업 재수행과 법당 보행 속도0 문제를 발견해 수정했다. 회귀 테스트 RED→GREEN 및 전체 테스트 통과.

방명록 데이터는 브라우저 API mock이며 운영 DB 쓰기를 하지 않는다. 실제 iPhone GPU/다중 사용자 부하와 운영 DB 저장/삭제는 미검증이다. 시설 좌표·방향, 운영 DB, 배포/병합은 변경하지 않는다. 사진 텍스처·새 조명·런타임 의존성을 추가하지 않는다.


브라우저 실행 검증:
- PC1200×900 / 모바일 모형390×844에서 네 단계 제작→완성→로컬 등 걸기, 현장 게시판 행동으로 방명록 열기와 한국시간 날짜·분, 자동 탑돌이 이동/중단, 방석 도착 후 삼배 시작/중단 확인. 두 환경 모두 pageerror0.
- PC에서 바퀴 마지막 구간의 한 바퀴 더 표시와 목표2바퀴 변경 확인. 이 장시간 보행 구간은 소프트웨어 렌더 부하 때문에600×600으로 점검했다. 마지막 탑돌이 회귀 점검은1200×900이다.
- 최초1200×900 테스트에서 프레임이1초를 넘으면 기존 실제시간 표본이 무효화되어 바퀴 수가 누락됐다. 자동 보행에 실제 사용한 제한 dt를 누적해 계수기에 전달하도록 수정했다. 이동각·반경·속도·순간이동 검증은 유지한다. 해당 회귀 테스트 RED→GREEN 및 전체123개 통과.
- 실제 방명록 DB 저장/삭제가 아니라 API mock 게시글로 작성 시각을 확인했다. 등 걸기는 Supabase 설정 없는 로컬 저장이다.

## 머지 뒤 고친 것 (클로드, 2026-11-11)

- **작업대 머리 위 이름이 옛 순서로 떠 있었습니다.** 작업대 배열은 골조 → 전기 → 한지 → 채색으로
  바뀌었는데 이름표만 `['골조','한지','채색','전기'][index]` 를 그대로 써서, 전기 작업대에 `2 한지`,
  한지 작업대에 `3 채색 · 지금`, 채색 작업대에 `4 전기` 가 붙었습니다. `지금` 표시는 제 자리에
  있는데 이름만 어긋나 반대로 더 헷갈렸습니다. `station.name` 에서 따오도록 바꿔 순서를 또 바꿔도
  어긋나지 않습니다. 확인: 전기까지 끝낸 상태에서 `1 골조 ✓ · 2 전기 ✓ · 3 한지 · 지금 · 4 채색`.

### 머지 전 확인한 것 (클로드)

- `npm ci` 취약점 0, `npx vite build` 성공, `node --test tests/*.test.mjs` 131 pass / 0 fail.
- 새 방문: 첫 화면 → 이름·기본 모습(더 꾸미기 접힘) → 남문 안쪽(26.5, 24.4) 입장 → 첫 방문 안내창.
  창 안에서 Shift+Tab 이 밖으로 나가지 않음.
- 재방문: `이어서 들어가기`, `검토법우 법우님, 다시 오셨군요.`, 모습 고르기 건너뜀, 제작 단계 보존.
- 제작 순서: 골조 → 전기(전구 연결·점등 시험) → 한지 → 채색 → 소원 적기 → stage 4.
  각 단계 토스트와 `오늘의 소임` 표시가 같은 순서.
- 자동 안내(🧭): 다섯 항목 모두 길을 찾고 실제로 걸어감. 방향키를 넣으면 멈춤.
- 자동 탑돌이: 한 바퀴로 끝나고 0.70바퀴에서 `한 바퀴 더` 가 나타남. 마치면 소임 체크.
- 방명록 게시판: 작업장 남문 서쪽에서 열리고 글마다 한국시간 날짜·분 표시(`2026.11.07 16:45`).
- 법당: 문으로 걸어 들어가고 걸어 나옴. `좌복` 단추로 빈 방석 선택 → 그 자리까지 걸어가 참배창.
  절하는 동안 인형 높이가 방석 위(0.230~0.288)에서 내려가지 않음. 저장한 머리·옷을 이어 씀.
- PC 1440×900 DPR2, 모바일 390×844 DPR3 모두 콘솔 오류 0. 안내 띠가 조이스틱과 겹치지 않음.
