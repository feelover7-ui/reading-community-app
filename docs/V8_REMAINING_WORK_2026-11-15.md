# v8 남은 작업 — 2026-11-15 현재 확인

최신 `origin/main`: `14edd925a4f118f5b30c64637eb55d2e8f2b99f0` (PR #61 갈색 좌복).
PR #35는 병합되어 닫힌 상태다. 이번 확인은 저장소 코드와 로컬 변경 대조이며, 운영 배포·DB 쓰기·실제 iPhone 재검증을 뜻하지 않는다.

운영 주소의 `v8.html`, `v8-map.js`, `v8-pilgrimage.js`도 읽기 전용으로 받아 모두 HTTP 200을 확인했다. 운영 지도 파일에는 `overview-map`, 여정 파일에는 새 `rack-arrive` 경로가 없고, HTML에는 `v8-youth-model.js` 연결이 없다. 방명록 UI 코드는 운영 여정 파일에 있다. 이는 배포된 소스 확인이며 전체 사용자 흐름이나 DB 저장 검증은 아니다.

## 지금 진행한 작업

- 사용자가 거절한 v5 얼굴을 확정하지 않는다. 별도 원본 모델 제작 스크립트 `scripts/build-reference-heads.py`로 남녀 얼굴·머리의 정면/45도/측면 3D 연구 모델을 새로 만든다.
- 새 얼굴은 이전 MakeHuman 얼굴이나 이전 머리 메시를 불러오지 않는다. 턱·볼·이마 윤곽, 눈구멍과 눈꺼풀, 들어간 안구, 머리의 층을 별도 작성했다.
- 결과는 `outputs/reference-heads-v6/`의 정적 GLB/Blender 파일과 실제 Blender 렌더다. 게임 스크린샷, 표정 리그, 전신 완성 또는 배포 결과가 아니다.
- 두 GLB를 Three.js `GLTFLoader.parseAsync`로 읽고 비어 있지 않은 경계와 유한한 정점 좌표를 확인했다. 애니메이션 클립은 둘 다 0개이며 검증 결과는 같은 폴더의 `verification.json`이다. 이는 로더 검증이지 실제 게임 연결/성능 시험이 아니다.
- 가방·앞뒤 끈은 v5 로컬 전신 모델에서 제거했다. 여성은 치마가 아닌 바지 복장을 유지한다.
