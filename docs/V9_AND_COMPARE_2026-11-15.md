## 1. 왜 겹치지 않는가

최근 60 커밋을 훑어 코덱스가 실제로 건드리는 곳을 확인했습니다.
`public/v8.html` · `public/v8-*.js|css` · `tests/v8-*.test.mjs` · `src/v8/` · `scripts/qa-v8-*`
뿐이고, `src/deungbul/` 은 60 커밋 동안 한 번도 바뀌지 않았습니다.

그래서 v9 는 **새 칸**에만 씁니다.

| 칸 | 누구 | 무엇 |
|---|---|---|
| `public/v8.html`, `public/v8-*.js|css`, `src/v8/`, `tests/v8-*` | 코덱스 | v8 |
| `v9.html`, `versions.html`, `src/v9/`, `tests/v9-*`, `scripts/version-compare.mjs` | 클로드 | v9 |
| `src/deungbul/`, `workers/` | 둘 다 | **읽기만** |
| `AGENTS.md`, `docs/`, `vite.config.js` | 둘 다 | **덧붙이기만** |

`vercel.json` 은 **고치지 않았습니다.** v9 는 Vite 진입점이라 번들되고,
바깥으로 나가는 연결이 없어 기존 `script-src 'self'` 그대로 돕니다.
(v8 만 `'unsafe-inline'` 과 날씨 API 가 필요해 따로 걸려 있습니다.)

## 2. v9 는 무엇인가

**한 장면 — 도량 마당 하나.**

v8 은 장면 아홉, 활동 서른여덟, 가만히 서 있을 때 화면에 떠 있는 UI 덩이가 아홉입니다.
넓어서 **장소가 아니라 지도**처럼 보입니다. 사용자가 좋아한 sansatemple 은 장면 하나입니다.
그래서 v9 는 마당 하나만 두고, 한 장면이 장소로 느껴지는지 먼저 봅니다.

- **좌표를 새로 만들지 않았습니다.** `src/deungbul/classicPlacement.js` 를 그대로 읽어
  구정탑·동상·법당 두 날개·칠보탑이 운영 맵과 같은 자리에 섭니다.
- **조형물도 새로 만들지 않았습니다.** `original/outdoorLandmarks.js` 의
  `buildPagoda`·`buildStatue` 를 가져다 자리만 옮깁니다.
- **엔진은 `three3d.js`** 입니다. 사람 인형·뒤따라가기 카메라·걷어내기·화면 위 글자가 거기 있습니다.

### 처음부터 제대로 넣은 것 (v8 은 바깥 파일로 덧댄 것들)

| | v8 | v9 |
|---|---|---|
| 기본 시점 | `campus` 를 직교(조감도)로 **강제**. `v8-view.js` 가 `setViewMode` 를 감싸 되돌림 | 원근 하나뿐. 되돌릴 강제가 없음 |
| ←→ | `update` 를 감싸 좌우 입력을 빼고 원래 값을 복원 | `steer()` 순수 함수. 브라우저 없이 시험 |
| 안개 | 본체 `near=62` 라 63칸 마당에서 한 번도 안 걸림 | `near 22 / far 230`, 먼 산 세 겹 |
| 가리는 나무 | `mergeStatic` 으로 묶여 있어 하나만 숨기면 묶음째 사라짐 | `world.addFade()` + `fadeOccluders()` |
| 코드 | 한 파일 1.43MB, 인라인 블록끼리 스코프가 달라 `window` 를 거쳐야 함 | ES 모듈. `import` 로 바로 부름 |

## 3. 비교 체계

표 하나와 확인기 하나입니다. **표가 거짓말을 못 하는 것**이 핵심입니다.

```
docs/version-features.json      기능 19개 × (v8·v9) 상태 + 근거(파일·찾을 글)
scripts/version-compare.mjs     근거를 저장소 파일에서 하나씩 확인. 어긋나면 종료 코드 1
tests/version-compare.test.mjs  같은 검사를 시험으로. 거짓 주장 5가지를 일부러 넣어 잡히는지 봄
versions.html                   같은 표를 브라우저에서 나란히
```

확인하는 것:

- 상태가 `있음`·`고침` 인데 근거 파일이 없거나 그 글이 파일에 없으면 **어긋남**
- 상태가 `없음` 인데 근거가 보이면 **어긋남**
- `있음`·`고침`·`없음` 아닌 글자를 쓰면 **어긋남**
- 두 쪽의 소유 파일 목록이 겹치면 **어긋남**

그래서 한쪽이 기능을 더하거나 지우면 표를 같이 고쳐야 시험이 통과합니다.
표는 **서로의 할 일 목록**이 됩니다.

지금 상태:

```
v8 에만: 다중접속, 대화, 등 만들기, 함께 걸리는 등, 탑돌이, 삼배, 법당 안, 자동 안내, 날씨
v9 에만: 가리는 것 걷어내기, 코드 묶음
둘 다 없음: 배경음악
```

## 5. 아직 아닌 것

- **이 컨테이너의 3D 는 소프트웨어 렌더(약 3fps)입니다.** 위의 2.5초 측정에서
  회전이 0.55 rad/s 로 나온 것은 프레임이 여덟 번밖에 안 돈 탓입니다.
  **눈높이 2.44 와 회전 2.1 의 실기기 체감은 확인하지 못했습니다.**
- 휴대폰 조이스틱은 보이는 것까지만 봤고 **손가락으로 끌어 걷는 것은 확인하지 못했습니다.**
- v9 에는 다중접속·대화·등 만들기·탑돌이·삼배·법당 안이 **없습니다.**
  표의 `v9: 없음` 이 그 목록입니다. 옮겼다고 표현하지 않습니다.
- 좌표는 게임용 배치입니다. **실측 지도가 아닙니다.**
- 운영 DB 에 쓰지 않았습니다. v9 는 아직 Supabase·relay 에 붙어 있지 않습니다.
