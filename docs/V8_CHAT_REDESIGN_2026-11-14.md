# v8 대화 기능 — 처음부터 다시 (2026-11-14)

사용자 요청: *"v8 버전 채팅기능 없다고 생각하고 처음부터 다시 짜서 기획안 보고해줘.
모든 맵에서 채팅이 보였으면 좋겠고, 따로 창 안 들어가도 채팅 내용들이 보였으면 좋겠어."*

**아직 코드는 고치지 않았습니다.**

## 1. 먼저 확인한 것 — 통신은 이미 다 돼 있습니다

코드를 열어 보니 **대화는 이미 방 전체(아홉 장면 전부)로 오갑니다.**

- **relay**: `workers/lantern-room/src/room.js` 의 `event()` 에 장면 검사가 없습니다.
  방 안 모두에게 갑니다.
- **Supabase**: `src/v8/realtime.js:146` 의 장면 채널이 `m.type!=='chat'` 으로 **대화를 일부러
  빼고** 있습니다. 대화는 방 채널을 탑니다.
- 받는 쪽 `receive()` 도 여러 갈래에서 장면과 무관하게 `append()` 를 부릅니다.

**그러니까 "모든 맵에서 보이게" 는 네트워크 일이 아니라 화면 일입니다.** 고칠 곳은 보여 주는 쪽뿐입니다.
서버·프로토콜·DB 를 건드리지 않습니다.

## 2. 지금 무엇이 문제인가

| | 지금 | 사용자가 원하는 것 |
| --- | --- | --- |
| 기록 | 왼쪽 다섯 줄, **14초 뒤 사라짐** | 늘 보임 |
| 어디서 한 말인지 | 표시 없음 | 아홉 장면이니 필요 |
| 큰 창 | 650px 모달, `setPaused(true)` 로 **세계가 멈춤** | 창에 안 들어가고 싶음 |
| 모바일 | 💬 를 눌러야 입력칸이 뜸 | 늘 보였으면 |
| 전송 한도 | relay 가 **용량 5·초당 1** 로 버림. 조용히 실패 | 알 수 있어야 함 |

## 3. 다시 짠다면 — 원칙 셋

1. **대화는 창이 아니라 화면의 한 부분이다.** 열고 닫지 않는다.
2. **방 하나 = 아홉 장면 전부.** 어디 있든 같은 대화를 보고, **어디서 한 말인지**를 같이 본다.
3. 가까이 있는 사람 말은 머리 위에도 뜬다(지금 그대로).

## 4. 화면

### `#talk` — 왼쪽 아래 상시 패널

- 기본 **여섯 줄**(모바일 셋). **사라지지 않습니다.** 위로 끌면 **60줄** 스크롤백.
- 한 줄의 모양:

  ```
  등불사장 · 작은 산새
  여기 등이 두 개 걸려 있네요
  ```

  **내가 있는 장면이면 장소 태그를 생략**합니다. 다른 장면의 말에만 붙습니다.
- 장면 이름이 깁니다(`한마음선원 · 3층 외부`). **짧은 이름 아홉 개**를 새로 정합니다:
  `도량 · 등불사장 · 무진향 · 2층 · 3층 · 3층밖 · 2층밖 · 서산정 · 대법당`
- 접기 단추(`⌄`). 접으면 한 줄로 줄고 **새 말 수**만 배지로 보입니다.
- **아무 말도 없으면 아주 작게** 둡니다. 빈 상자가 화면을 먹지 않게.
- 내 말은 살짝 다른 바탕(지금 `stream-line.mine` 그대로).

### `#talkInput` — 패널 바닥에 붙은 한 줄

- **PC: 늘 보입니다**(흐리게). `Enter` 로 초점이 가고, `Esc` 는 초점만 뺍니다(패널은 그대로).
- **모바일: 💬 로 올립니다.** 키보드는 `visualViewport` 로 피합니다(이미 있는 코드).
- 보내면 입력칸에 초점이 남아 연달아 칠 수 있습니다.

### 머리 위 말풍선

지금 그대로(10초). **같은 장면 사람만** 띄웁니다. 다른 장면 사람의 말은 패널에만 뜹니다.

## 5. 없앨 것

- **`chat-modal`(650px)**. 방 이름·접속 단추는 **설정**으로 옮기고, 60줄 기록은 패널 스크롤백이
  대신합니다. `채팅` 단추도 없앱니다(늘 보이니 열 것이 없습니다).
- `unread` 배지는 **접었을 때만** 씁니다.

## 6. 같이 고칠 것

- **전송 한도를 보여 줍니다.** relay 는 용량 5·초당 1 회복이라 연타하면 서버가 버립니다.
  지금은 조용히 실패합니다. 남은 횟수가 0 이면 입력칸을 잠그고 `잠시 뒤에 보내집니다` 를 띄웁니다.
- **장면별 접속자 수.** 지금은 총 인원만 있습니다. `도량 3 · 등불사장 1` 로 쪼개면
  아홉 장면에 흩어진 사람이 보입니다. 이미 오가는 `scene` 값으로 셉니다. **새 통신 없음.**
- 혼자일 때 패널에 `지금은 혼자 있습니다` 한 줄.

## 7. 접근성·안전

- 패널은 `role="log" aria-live="polite"`. 지금 왼쪽 기록은 `aria-hidden` 인데, 큰 창을 없애면
  읽어 줄 곳이 여기뿐이라 바꿔야 합니다.
- **한글 조합 중 `Esc` 는 조합 취소**라 넘깁니다(이미 있음).
- 입력칸에 초점이 있으면 방향키가 걷기로 가지 않습니다(이미 있음).
- 들어오는 글자는 `textContent` 로만 넣습니다. 이름·말 길이 제한은 지금 값(160자) 유지.

## 8. 건드리지 않는 것

- 서버(`workers/lantern-room/`), 프로토콜, Supabase 표, `src/v8/` 통신 어댑터.
- 말풍선, presence, 걷기.
- **이것은 화면 작업입니다.** 통신은 이미 원하는 대로 돼 있습니다.
