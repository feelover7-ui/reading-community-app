# 승인된 후속 작업

사용자 승인: 시안 기준 별도 청년 모델, 작업장 등걸이대에 직접 걸기, 지도 아이콘에서 전체 조감도를 열고 장소를 즉시 선택한다.

1. Blender에서 남녀의 얼굴·옷·손발 메시를 제작하고 GLB와 동일 메시의 브라우저 데이터를 함께 출력한다. 기존 관절 및 접지 동작과 외형 저장을 유지한다. 원본 승인 이미지가 현재 파일에 없으므로 저장된 승인 기준표(세이지 재킷/여성 배색 재킷, 옆가르마/단발, 약 6등신)를 사용하며 이미지와 정확히 일치한다고 주장하지 않는다.
2. 완성한 등은 걸기 전까지 전시장/공유에 노출하지 않는다. 등걸이대 앞에서 발원 입력·걸기·점등을 마치고 참배를 선택한다. 기존 저장 등은 걸린 상태로 유지한다. 재방문 제작과 중복 제출도 처리한다.
3. 실제 v8 도량 장면을 촬영한 조감도에 장소 버튼을 표시한다. 상시 지도 아이콘과 기존 지도 버튼은 같은 화면을 열고, 내부에서도 모든 장소로 바로 이동한다.
4. 상태 전이·공유 시점·모델 관절을 검증하고 PC/모바일 실제 장면을 확인한 뒤 PR/배포한다. 실기기 검증과 모델의 시안 유사도는 수치 검사와 구분한다.
