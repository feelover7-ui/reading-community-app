# 첫 접속·캐릭터 구현 계획

사용자가 통합 시안을 승인하고 구현을 요청했다. 운영 코드에는 구현 가능한 경량 기하를 적용하며 생성 이미지의 미세한 질감/모션 캡처 수준을 그대로 보장하지 않는다.

- [x] 공통 캐릭터 디테일: 약4등신 머리 비례, 귀·코·눈썹, 손바닥/엄지, 조끼 주머니·단추·어깨. 기존 모습 선택/키/관절/방석 접지를 보존한다.
- [x] 첫 화면: 조용한 입구 삽화와 버튼 하나, 준비/오류 상태 및 접근성. 전체 3D의 입장 전 연속 렌더 금지 유지.
- [x] 첫 입장: 같은 장면 위에서 이름/기본 모습 설정, 세부 꾸미기는 접기. 입장 후 선택 가능한 활동 안내. 재방문은 저장된 모습으로 이어서 입장, 수정 경로 유지.
- [x] 캐릭터 접지/비례·입장 상태 검증과 빌드, PC/모바일 첫 입장/재방문/꾸미기/제작·법당 삼배 확인. 운영 DB 쓰기 없음.
- [x] 독립 검토 및 기존 PR40 업데이트. 병합/운영 배포 없음.
