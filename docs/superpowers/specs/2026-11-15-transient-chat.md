# v8 게임 중 대화 표시

사용자 승인: PC·모바일 모두 평소 패널을 없애고 최근 글만 표시한다. PC 5개/모바일 3개, 8초 표시 뒤 1초 페이드. Enter 또는 대화 버튼으로 입력줄을 열고 성공 시 입력·키보드를 닫는다. 빈 Enter/Esc는 닫기, 실패 초안·한글 조합 보호는 유지한다.

왼쪽 위 안내 아래 글을 표시하며 글은 포인터 입력을 가로채지 않는다. 입력줄은 모바일 키보드 위에 놓고 게임 캔버스 크기를 유지한다. 입력 중 모바일 이동·활동 버튼은 숨긴다. 기록 버튼으로 이번 접속 최근 60개를 읽으며 새 글이 와도 읽던 위치를 지킨다. 기존 전송 방식·공간·제작 기능은 유지한다.

방식: 기존 상시 패널 유지보다 일시 메시지/입력줄/기록을 분리하는 승인안을 적용한다. 영구 서버 기록이나 팀별 채팅은 추가하지 않는다.
