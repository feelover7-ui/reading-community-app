# v8 온라인 참배 전면 재설계

## 의도

v8을 여러 게임 기능이 병렬로 놓인 3D 맵에서, 실제 한마음선원 안양 본원을 근거로 한 차분한 온라인 참배 경험으로 재편한다. 온라인 참배가 본편이고 등 만들기는 발원을 돕는 선택 가능한 과정이다. 사용자가 마친 뒤 남겨야 할 주된 감정은 실제 도량을 다녀온 듯한 고요함이며, 다른 참배객의 흔적은 절제된 온기로만 드러난다.

## 목표

- 첫 화면부터 회향까지 `도착 → 등 만들기(선택) → 탑돌이 → 대법당 삼배 → 등 걸기·발원`의 한 여정을 분명히 한다.
- 운영 UI를 안내형 몰입 구조로 바꾸고 상시 게임 HUD를 숨긴다.
- 외부의 법당·구정탑·칠보탑·대행선사 동상 위치와 방향은 유지하고, 위성·공식 사진 근거를 우선한다.
- 불교문화회관 등불사장과 5층 대법당은 공식 사진에서 관찰 가능한 구조·비례·재료를 기준으로 다시 만든다.
- 검증되지 않은 1·2·3층 내부를 실제 공간처럼 꾸미지 않는다.
- PC와 모바일에서 문 통과, 장소 이동, 참배, 제작, 재방문이 설명 없이도 가능해야 한다.

## 비목표

- 확인 자료가 없는 본원 전 층의 정밀 복원
- 공식 사진 파일을 앱 안에 복제하거나 텍스처로 사용하는 것
- 로그인·결제·새 데이터베이스·새 실시간 서버 도입
- 기존 등·방명록·접속 기록 형식을 파괴하는 마이그레이션
- 경쟁·순위·전투·실패 중심 게임화

## 실패로 보는 결과

- 도량보다 버튼·재화·레벨·퀘스트가 먼저 보인다.
- 임의로 만든 로비나 단축 지형을 실제 배치처럼 제시한다.
- 대법당 입장 시 본존불 대신 벽·기둥·측면 통로가 첫 화면을 차지한다.
- 등 만들기가 제작 변화 없이 점수 미니게임으로만 보인다.
- 모바일에서 조작 UI가 참배 대상이나 문을 가린다.

## 선택한 접근

### 검토한 접근

1. 기존 기능을 유지하고 시각 요소만 교체: 회귀 위험은 작지만 게임 HUD와 가상 로비라는 근본 문제를 남긴다.
2. 모든 장면을 하나의 연속 3D 건물로 재작성: 이상적이지만 확인되지 않은 층 구조를 만들어야 하고 현재 배포 위험이 너무 크다.
3. **사진 근거가 있는 공간을 깊게 재구성하고, 확인되지 않은 연결부는 정직한 전환 공간으로 축소**: 정확성과 구현 안전성을 함께 지킨다.

선택은 3번이다. 외부 위치를 보존하고 등불사장·대법당에 품질을 집중한다. 3층 문에서 5층 대법당으로 가는 과정은 최소한의 내부 진입과 승강기 전환으로 설명하되, 근거 없는 복도·방은 만들지 않는다.

## 경험 흐름

1. 전체 도량 전경과 절제된 종소리로 도착한다.
2. `참배 시작`을 주 행동으로 제시하고 `등을 만들고 갈게요`, `자유롭게 둘러보기`를 보조 선택으로 둔다.
3. 등 만들기를 선택하면 하나의 등 모형이 골조·전기·한지·채색을 거치며 실제로 변한다. 건너뛰면 바로 참배 동선으로 간다.
4. 완성한 등을 든 채 구정탑을 시계방향으로 자동 한 바퀴 돈다.
5. 3층 외부 문에서 본원 내부로 들어와 승강기 전환 뒤 5층 대법당에 도착한다.
6. 본존불을 정면으로 바라본 뒤 자연스러운 삼배를 한다.
7. 등을 걸 때 처음 이름과 발원문을 입력한다.
8. 점수·보상 대신 오늘 밝힌 등과 짧은 회향 문장을 보여 준다.
9. 재방문자는 이전 등을 확인하고 참배·둘러보기로 바로 갈 수 있다.

## UI

- 첫 화면은 도량 전체화면이며 큰 카드형 프로필·재화·레벨·일일 임무를 보이지 않는다.
- 상단에는 지도, 음향, 접근성만 작게 둔다.
- 하단에는 현재 맥락에 필요한 행동 하나만 둔다.
- 대상 근처에서만 한 줄 설명을 띄우고, 선택하면 공식 출처를 포함한 상세 설명을 연다.
- 지도는 실제 도량 안내도처럼 구성하고 먼 장소를 즉시 이동한다. 정확한 외부 배치를 이동 편의를 위해 축약하지 않는다.
- 모바일 터치 대상은 최소 44px이며 안전영역과 동적 뷰포트를 따른다.

## 외부 공간

- 동상·구정탑·칠보탑·법당·등불사장 기준점과 방향을 유지한다.
- 원형 탑 마당, 사선 외곽, 곡선 길, 잔디·포장 경계는 승인된 배치와 사진 근거를 함께 따른다.
- 등불사장 입구 앞 길 끊김을 없애고 길 색을 주변 포장과 섞는다.
- 구정탑에서 법당으로 향하는 인위적인 직선 안내길·화살표는 두지 않는다.
- 동상과 탑 바로 앞 참배면은 비우고 주변 잔디와 식재를 자연스럽게 잇는다.
- 서산정·부도탑의 기존 사진 기반 지형과 외형은 보존한다.

## 등불사장

공식 `one_news/268`, `one_news/322`, `one_news/348`에서 관찰한 불교문화회관을 기준으로 한다. 높은 산업형 천장, 연두색 벽, 밝은 회색 바닥, 긴 형광등, 대형 셔터, 베이지색 커튼, 철제 비계, 이동식 작업대, 벽면 수납, 넓은 중앙 조립면을 반영한다.

- 불바퀴등은 실제 제작물처럼 크고 중앙에서 조립 가능한 위치에 둔다.
- 네 공정은 네 개의 고정 게임 부스가 아니라 하나의 제작물과 이동 가능한 재료 구역으로 연결한다.
- 골조·전선·한지·채색의 시각 상태가 저장 상태와 정확히 일치한다.
- 점수·타이머는 사용자에게 보이지 않고 안내 문장과 제작 변화만 남긴다.

## 대법당

공식 `one_tour_0201.jpg`, `0202.jpg`, `0203.jpg`의 관찰을 기준으로 한다.

- 넓은 중앙 흰색 법석, 정면 불단·본존불·금빛 후불 목탱화·닫집을 주축으로 한다.
- 반복 좌복 30개와 중앙 시야를 막는 기둥 배치를 폐기하거나 실제 측면 구조로 이동한다.
- 천장고, 격자 천장, 단청, 별화, 측면 창호의 리듬을 강화한다.
- 입장 카메라는 본존불 정면을 보여 주고 자유 이동 뒤에도 다시 정면을 찾을 수 있다.
- 삼배 중 발·무릎이 바닥이나 좌복에 묻히지 않으며, 일반 UI는 숨긴다.

## 본원 연결 공간

- 2층과 3층을 같은 방에 간판만 바꿔 표시하지 않는다.
- 사진 근거가 없는 1·2·3층은 지도 목적지가 아니라 필요한 출입·승강기 전환으로 축소한다.
- 3층 외부 문 → 내부 전환 → 5층 승강기 → 대법당의 관계를 분명히 한다.
- 직접 걷는 사용자는 문턱을 넘으면 자동 입·퇴장하고, 지도 이동 사용자는 같은 방향의 안전한 도착점에 선다.

## 캐릭터와 의식

- 남녀 모두 5.7~6.5등신의 현대적인 청년 참배객으로 보인다.
- 과장된 4등신, 화려한 게임 의상, 캐릭터가 공간보다 튀는 색을 피한다.
- 걷기·합장·반배·삼배·등 들기가 한 리그에서 자연스럽게 연결된다.
- 탑돌이는 조작 실수를 막기 위해 자동이며 한 바퀴만 돈다.

## 조용한 공동체

- 상시 채팅 UI를 핵심 경험에서 제외한다.
- 다른 접속자는 멀리 보이는 조용한 참배객으로 남긴다.
- 접속자 버튼을 열었을 때만 장소별 사람 목록을 보여 주며 방 이름은 없다.
- 방명록은 한국 날짜와 시간을 표시한다.
- 다른 사람의 등·발원문은 선택해서만 읽으며 경쟁 지표는 두지 않는다.

## 호환성과 검증

- 기존 저장 데이터, 등 공유, 방명록, Realtime/relay 프로토콜은 호환한다.
- 레벨·재화·기존 기록은 데이터에서 삭제하지 않고 참배 UI에서 숨긴다.
- 새 라이브러리를 추가하지 않고 기존 Three.js·Vite·JavaScript를 사용한다.
- Node 회귀 테스트, Vite 빌드, Chromium PC 1440px, 모바일 390×844를 검증한다.
- 실제 iPhone Safari 검증 없이는 실기기 완료라고 표현하지 않는다.
