# 편한 제작·참배와 방명록
사용자가 마지막 전체 기획을 승인하고 진행을 요청했다. 기존 React/Vite/Three.js 및 실제 보행 충돌을 유지한다.
- 제작 순서 골조→전기→한지→채색. 반복 터치는 줄이고 최종 소원/점등은 채색 뒤. 기존 저장 데이터는 버전을 구분해 완료한 작업을 보존하며 순서를 복원한다.
- 사용자가 누르는 목적지 안내/다음 작업대 이동. 충돌을 통과하지 않고 수동 이동·중단·페이지 이탈로 취소한다. 이동 중 원격 제작/참배 없음.
- 탑돌이는 자동 한 바퀴 기본, 마지막 구간에서 한 바퀴 더 선택, 언제든 종료. 카메라는 탑 중심의 안정된 구도.
- 법당은 빈 방석을 골라 자동 이동한 뒤 참배 선택창을 열고 사용자 선택으로 시작. 기존 걸어서 출입/수동 이동 보존.
- 기존 방명록 공유 저장소를 재사용. 작업장 출입구 옆에 실제 게시판/근접 행동 배치. 게시글마다 한국시간 날짜와 시각 표시. 저장/삭제 보안과 초안 보존 유지.
- 배치/방향, 운영 DB, API/비밀키, 배포/병합 변경 없음. 사진 텍스처/조명/의존성 추가 없음. 새 PR 하나, 본문 검증 못 했음.
