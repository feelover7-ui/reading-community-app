# 등불사장 길·시점·개체 설명

현재 main 05708b3에서 작업한다. 이전 본원 앞면/1층 출입구는 스케치 요청으로 남겨 두고 이번 구현 범위에 섞지 않는다. 작업장/본원/탑/동상의 위치와 방향, 원본 제작·출입·공유 기능은 유지한다.

- 문 바깥 바닥은 z26에서 끝나고 작업장 경계는26.6, 길 시작은26.8이어서 시각적·보행 틈이 있다. S곡선 시작만 문 안쪽25.7까지 겹쳐 지면·충돌을 잇는다.
- 작업장 진입 시 북쪽 네 작업대를 정면으로 바라보는 시점으로 복귀한다. PC 기본은 네 작업대와 사람을 함께 담는 구도, 모바일은 가까운 기본 구도를 유지하면서 정면 방향으로 맞춘다. HUD/미니맵의 실제 점유 영역을 피해 PC 작업대를 배치한다.
- 수동 회전/확대/눈높이는 같은 방문 동안 덮어쓰지 않는다. 작업장 보기 버튼으로 자동 구도를 복원한다. 재입장 시 다시 정면으로 맞춘다. 카메라 전환 중 이동은 실제 화면의 yaw를 따른다. 전체 보기·모습 선택·대화/의식이 우선한다.
- 작업대에 짧은 번호/이름/현재 단계 표식을 붙여 순서를 한눈에 읽도록 한다. 원격 제작이나 새로운 제작 단계를 만들지 않는다.
- 구정탑·칠보탑·동상 가까이에서 작은 이름/클릭 안내만 표시한다. 개체 직접 클릭/터치나 해당 안내를 선택하면 공식 설명 요약과 원문 링크를 연다. 본문 자동 모달/메뉴 탭은 만들지 않는다. 드래그·핀치·UI 조작·가려진 개체는 클릭으로 처리하지 않는다.
- 접근성을 위해 작은 근접 안내는 키보드 버튼으로도 작동한다. 삼배·탑돌이 작업과 설명 선택은 분리한다. 공식 원문은 출처에 연결하고 독자 요약을 사용한다.
- 기존 법당 자동 시점·실내 출입과 위치를 보존한다. 동상 앞은 동상과 사람을 담는 자동 구도를 추가하되 동상을 회전하지 않는다.

접근 방법: 전체 맵만 넓게 보는 방식은 작업대가 너무 작다. 사람만 따라가는 방식은 네 작업대가 잘린다. PC 작업장 영역을 대상으로 화면 점유 영역을 계산한 자동 구도와 수동 전환을 사용한다. 구현 판단이며 추가 승인을 묻지 말라는 기존 사용자 지시를 따른다. 새 의존성·운영 DB 쓰기·병합/운영 배포는 하지 않는다.
