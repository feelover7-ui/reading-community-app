# 승인된 중앙 잔디·참배 마당·오른쪽 식재

사용자가 마지막 스케치 exec-425c5b2a-141f-4512-838e-2ec09c1e4cb8.png를 승인했다. 천막 자리와 주변 녹지를 중앙의 한 잔디면으로 합치되 동상 앞과 구정탑 주변에서 잔디를 물리고, 구정탑 오른쪽 가장자리를 소나무/낮은 관목/자연석으로 채운다. 실제 위성사진의 측량 복원이 아니라 사용자가 선택한 조경 변경안이다.

동상·구정탑·법당·칠보탑·작업장 위치와 방향, 3층 문, 연결길과 원형 보행 동선을 유지한다. 본원1층 출입구/앞면은 여전히 별도 스케치다. 담장·새 조명·라이브러리·운영 DB 쓰기·병합/배포는 추가하지 않는다.

단일 중앙 잔디의 부드러운 경계를 좌표 데이터로 관리하고 옛 여러 화단 렌더를 대체한다. 동상 앞은 빈 석재 참배 공간으로 유지한다. 탑 주변 잔디/관목/바위가 탑돌이와 보행원을 침범하지 않는다. 오른쪽은 기존 높은 도량 가장자리에 식재와 낮은 바깥 지면으로 이어지는 사면을 두어 식재가 허공에 뜨지 않게 한다. 새 식재 영역은 출입 동선으로 사용하지 않는다.

작은 구형 나무 대신 가지와 겹친 수관을 갖춘 경량 소나무를 사용한다. 낮은 관목·자연석은 인스턴스화하고 수관 가림 처리는 기존 fadeables에 연결한다. 모바일 기본 표현은 유지하고 고비용 후처리는 사용하지 않는다. 미니맵도 같은 잔디·식재 데이터를 사용한다.
