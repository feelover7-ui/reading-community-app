# v8 위치 전송 최적화
사용자가 제안한 정지 전송 중단/속도 기반 예측/인원별 간격/장소별 전송을 승인했다.
기존 방 채널의 Presence/ref 퇴장과 방 전체 채팅, 초안/재접속/BFCache 보호를 유지한다. 위치/인사는 장소별 채널로 옮긴다. 늦은 입장 스냅샷은 참가자 전용 수신함으로 보내 불필요한 재방송을 피한다. 채널은 같은 SDK 소켓을 공유하며 DB·환경변수·의존성·게임 규칙은 변경하지 않는다.
UI는100ms마다 실제 위치/속도를 샘플한다. 전송기는 마지막 방송으로 상대가 예측할 위치와 실제 차이, 이동 시작/정지/회전/외형 변경을 비교한다. 정지 재방송은 없고 일정한 직선 이동도 예측이 맞으면 재방송하지 않는다. 참가자가 늘면 중간 보정 간격을 늘린다. 멈춤과 장면 전환은 보존한다. 수신은 위치와 속도로 그리되 장시간 잘못된 이동은 제한한다.
서버 초당 제한은 남아 있다. 합성 직선 이동 시험만으로 임의 조작40명 안정성을 보장하지 않는다. 정지/직선/회전/정지 재개와 같은 장소/분산 장소, 늦은 입장·재접속을 구분해 검증한다.
