# 서산정 사진 기반 개선

사용자가 승인한 v8 화면 시안에 따라 구현·배포한다. 기존 왼쪽 부도탑(-11,0), 오른쪽 위 건물(9,-17), 아래 입구(2,25.6), 출입/참배/둘레길, 카메라와 기존 계단은 유지한다. 계단형 잔디 블록 대신 연속 지형을 그리며 groundHeight와 동일한 높이로 바닥·길·수목을 배치한다. 기존 walkRegions/obstacles는 유지한다.

부도탑의 황금 점과 원뿔 꽃잎을 사진의 석재 봉오리·감싸는 꽃잎·말린 받침과 낮고 넓은 자연석으로 바꾼다. 건물의 목재·유리 창호·기와와 처마 서까래, 소나무 수관, 관목을 구체화한다. 좁은 진입길은 기존 계단 끝에 연결된 자연스러운 곡선으로 다듬는다.

본원 외관 파일과 UI·캐릭터·통신은 수정하지 않는다. 독립 public/v8-seosan-photo.js와 HTML 로더 한 줄로 한정한다. 사진 원본·생성 이미지를 앱에 넣지 않는다. 실제 치수·측량 복원으로 주장하지 않는다. 본원·다른 장면 및 2D fallback은 유지한다.
