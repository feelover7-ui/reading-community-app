# 걸어서 퇴장·사진 기반 내외부 표현

사용자는 입장과 동일한 걸어서 퇴장, 사진 기반의 내부와 외부 사실감 보강을 요청했다. 기존 질문 생략·자율 진행 지시에 따라 기존 Three.js에서 직접 구현한다.

- 내부 출구의 문턱을 바깥 방향으로 실제 넘으면 기존 도량 복귀를 실행한다. 입장 직후 정지, 옆 통과, 텔레포트, 대화/절하기 중 이동으로 퇴장하지 않는다. 수동 나가기와 BFCache 복원은 유지한다.
- 공식 사진 one_about_01, one_status_02와 기존 0201/0501에서 관찰한 특징을 반영한다: 차분한 분홍빛 석재 외벽, 검은 기와, 청록/적갈색 처마 구조, 연한 회색 대형 포장, 낮은 녹지 경계, 내부 어두운 목재 하부 벽과 밝은 창·천장 격자·단청.
- 기존 위치·방향·도량 외곽·길·3층 연결·실내 천장고6·사람/불상/좌복·카메라를 보존한다. 담장·새 조명·라이브러리·사진 텍스처를 추가하지 않는다. 원본 사진은 앱에 넣지 않는다.
- 접근 방식: 원본을 붙인 면은 시점 변경에 평면으로 보이며 재배포 제한이 있다. 전체 스캔 재구성은 실측/다각도 자료가 없다. 기존 구조에 직접 만든 재질과 인스턴스 장식·실제 열린 출구 문틀을 더하는 방식을 선택한다(구현 판단).
- 모바일은 저비용 기본 표현을 유지하며 정밀 처마 장식은 quality 그룹으로 제한한다. 사진 일치·실측 복원·실제 아이폰 성능 완료라고 말하지 않는다.
