# v8 공간 이동 통일
사용자가 보고된 개선안 전체 구현·배포를 승인했다. PC/모바일 공통으로 문턱 방향 통과와 계단 끝에서 양방향 자동 이동, 문 클릭/터치 자동 걷기·입장, 안전한 도착 위치·시선과 재진입 방지, 서산정 포함 아홉 장소의 지도 즉시 이동·활동 안내용 로비 경로 연결, 이동 취소·안내 문구를 구현한다. 직접 접근한 승강기는 층 선택, 지도로 층을 정한 경우 해당 층까지 안내한다. 활동/참배/설명 대상은 자동 실행하지 않는다. 건물 위치·외관·통신·DB는 바꾸지 않는다.
새 travel 모듈에서 경로 그래프와 출입 판정을 관리하고 app은 기존 enterScene/showElevator로 이동한다. 경계 통과와 명시적 목적지 도착을 구분하며 단순 근접으로 전환하지 않는다. 문 앞 정지·문 옆 통과·도착 직후·모달·수행·경로 중 수동조작·취소·불가능한 경로를 검증한다. 3D뿐 아니라 2D fallback에서 지원하는 연결도 확인한다. 사진 기반 외관은 그대로 유지한다.

지도는 장소를 고르면 걷지 않고 즉시 이동한다는 추가 사용자 지시를 따른다. 지도 이동은 진행 중 경로를 취소한다. 같은 장소 선택은 위치를 초기화하지 않고 창만 닫는다.
