# v8 높은 등불사장·보이는 제작·현대 청년
사용자는 개선안 요청 뒤 두 번 진행을 지시해 구현까지 승인했다. 현재 v8만 수정한다.
- 기존 약 38.2×29.7 게임 단위를 48×36(면적 약1.52배)으로 넓히고 구조 상부를 약11.4 높이로 올린다. 실측 미터가 아니다. 입구/출구와 새 이동 모듈을 함께 검증한다.
- 불바퀴등을1.45배로 확대해(0,-3.2) 중앙 가까이에 배치하고, 작업대·공동골조·전시벽은 주위로 분리한다. 점등·실제 전시등 보존.
- 네 큰 공정 골조→전기→한지→채색. 기존 다섯 저장 단계는 호환 유지하며 실묶기/배접은 한지의 두 하위 작업으로 표시한다. 동일한 등 모형이 실제 초안 상태에 맞춰 자라도록 제작 중 계속 보여준다. 선택 모양과 색, 오류·점수·취소·초안 복원·발원 작성·전시·보상은 유지한다.
- 현대적 청년: 약5.5등신, 작은 머리/목/어깨, 현대 상의·일자 바지·스니커즈, 자연스러운 머리. 피부/성별/머리4종/의상·앞치마/금색 장식 호환. 로컬·다른 접속자·초상에 같은 결을 적용한다. 관절 인터페이스와 합장/반배/걷기/삼배를 보존하고 검증한다.
- 사진/외부 모델/새 라이브러리 없이 절차적 모형. DB·통신 변경 없음. PC/모바일 대체 그림과 저감 설정도 고려한다.
