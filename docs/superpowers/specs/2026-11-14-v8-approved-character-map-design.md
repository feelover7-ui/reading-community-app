# v8 승인 캐릭터·전체 장소 지도 설계

## 의도

운영 캐릭터를 대화에서 승인된 현대 청년 시안과 같은 비율·복장으로 다시 만들고, 지도 버튼 하나로 아홉 장소를 한눈에 보고 즉시 이동하게 한다. 현재 운영판의 큰 머리·굵은 원통 팔다리·3D와 초상화 불일치를 승인 시안으로 간주하지 않는다.

## 승인 기준

- 캐릭터는 4등신·치비·마스코트가 아니다. 전체 키 대비 머리 높이를 약 1/6로 두는 단정한 현대 청년 비율이다.
- 남성 기본 복장: 짙은 세이지 재킷, 흰 셔츠, 차콜 슬랙스, 아이보리 운동화.
- 여성 기본 복장: 세이지 상부와 아이보리 하부가 나뉜 배색 재킷, 흰 이너, 차콜 슬랙스, 아이보리 운동화.
- 남성은 단정한 옆가르마, 여성은 턱선 단발이다. 얼굴은 작은 눈·눈썹·코·옅은 미소로 시안의 차분한 인상을 유지한다.
- 손에 든 등이나 생활한복을 새로 추가하지 않는다. 이번 기준표에 없는 장식을 임의로 넣지 않는다.
- 정면 초상화와 실제 3D 캐릭터는 같은 머리 크기, 몸통 길이, 다리 비율, 복장 색 분할을 쓴다.

## 구현 방식

기존 `HanmaumAvatar.createActor()`와 `portrait()`의 계약을 유지하면서 메시만 다시 만든다. 총 높이는 약 2.45 world unit, 머리 시각 높이는 약 .40으로 고정해 6등신 전후로 읽히게 한다. 몸통은 재킷의 앞판·깃·이너가 구분되는 완만한 회전체/평면 조합, 팔다리는 길고 가는 원통과 자연스러운 손·신발로 만든다.

기존 리그 키 `root, body, torso, head, arms, elbows, wrists, hands, legs`, 저장 외형 `gender, hair, skin, hairColor, robeColor`, 의상 ID, 네트워크 payload는 바꾸지 않는다. `basic`만 승인 복장을 정확히 표현하고 기존 해금 의상은 같은 새 체형 위에 기존 색·앞치마·가사 장식을 호환한다.

## 전체 장소 지도

지도는 긴 소개 카드 목록이 아니라 한 화면의 장소 선택판이다. 다음 아홉 곳을 모두 동시에 표시한다.

1. 전체 도량
2. 등불사장
3. 본원 1층 무진향
4. 본원 2층 로비
5. 본원 2층 외부
6. 본원 3층 로비
7. 본원 3층 외부 구정탑·동상
8. 본원 5층 대법당
9. 서산정·부도탑

PC는 외부 공간과 본원 층을 시각적으로 묶은 배치판, 모바일은 같은 아홉 곳을 3×3의 압축된 선택판으로 표시한다. 각 장소는 최소 44px이고 현재 장소를 명확히 표시한다. 다른 장소를 누르면 확인 창이나 자동 보행 없이 기존 `enterScene(id)`로 즉시 이동한다. 기존 문·계단을 직접 걷는 이동은 그대로 남는다.

## 보존 범위

- 동상·구정탑·칠보탑·법당·등불사장·본원·서산정의 좌표, 방향, 충돌, 출입문은 바꾸지 않는다.
- 삼배·합장·반배·탑돌이·작업 동작과 발 접지를 깨뜨리지 않는다.
- 저장 기록, 기존 의상 구매, 다중접속 외형, 장면 ID 아홉 개를 마이그레이션하지 않는다.
- 채팅, DB, 릴레이, 조경, 건물, 카메라를 이번 변경에 섞지 않는다.

## 검증 기준

- 남녀 기본 3D 모델의 키/머리 비가 5.7~6.4이고 발이 바닥 아래로 내려가지 않는다.
- 정면 SVG 초상화에 남녀 승인 복장 색 분할과 긴 다리 비율이 보인다.
- 기존 네 가지 머리, 모든 의상, 전체 관절 리그와 동작 테스트가 통과한다.
- PC 1440×960과 모바일 390×844에서 장소 아홉 곳이 지도 창 안에 동시에 보이고 각 버튼이 44px 이상이다.
- 지도 장소 선택은 즉시 해당 장면으로 바꾸고 현재 장소 선택은 중복 전환하지 않는다.
- 전체 Node 테스트, production build, 브라우저 페이지 오류 검사를 통과한다.

## 제외·한계

- 실사 인물 모델, 모션캡처, 외부 GLTF, 새 라이브러리는 사용하지 않는다.
- 실제 iPhone Safari와 80명 동시 렌더링은 별도 운영 검증 항목이다.
