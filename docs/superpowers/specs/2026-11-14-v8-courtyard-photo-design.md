# v8 도량 사진 기반 외관

사용자가 뉴스 사진을 참고한 v8 전체 지도 시안을 승인하고 PR을 요청했다. 최신 main a4ae14d에서 별도 브랜치로 진행한다.

기존 buildSite의 건물·탑·동상 위치, 충돌, 층 연결, 도로, 카메라는 유지한다. 마당 바닥은 밝은 화강석과 절제된 분홍색 끼움돌, 본원은 석재·기와·단청과 유리문, 수목은 소나무 수관으로 다듬는다. 행사 천막·연등망·인원은 상설 시설로 추가하지 않는다. 생성 시안의 모든 미세한 장식을 그대로 재현하는 범위는 아니다.

선택: 기존 단일 HTML을 대규모 편집하는 대신 독립 외관 스크립트가 buildSite 생성 중 시각 helper만 보완한다. HTML은 app.js 앞 로더 한 줄만 추가한다. Claude의 모바일/캐릭터/채팅/통신 영역은 편집하지 않는다. 서산정은 이번 도량 PR에 포함하지 않는다.

사진은 공식 뉴스 419, 413, 412를 참고하며 원본 저작물을 앱에 복사하지 않는다. 새 라이브러리·DB·환경변수·운영 배포 없음. 절차적 Canvas 재질과 기존 Three.js만 사용한다. 2D 대체 화면은 기존 기능 그대로 유지한다.
