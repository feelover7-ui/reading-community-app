# 등불사장 퇴장 뒤 캐릭터 숨김 수정

## 원인과 수정

등불사장 남문을 실제 이동 입력으로 통과하면 도량의 (39.2, 0.12, -4)에 도착한다. 뒤따라보기 카메라는 출입구 뒤 벽과 충돌해 가까워진다. 기본 카메라가 거리 4 미만에서 캐릭터를 숨긴 뒤, 실외 카메라가 높이와 거리를 다시 조절하면서 숨김 상태를 그대로 남겼다. 재현 당시 최종 카메라는 (42.523, 2.77, -4)였고 캐릭터를 보여줄 공간이 있었지만 `player.visible=false`였다.

`v8-view.js`의 실외 뒤따라보기 마지막 단계에서 최종 카메라와 캐릭터 가슴 중심 사이 거리를 기준으로 표시를 결정한다. 1.2 이하의 매우 가까운 경우에는 몸이 화면을 덮지 않도록 숨긴다. 벽 충돌 처리는 유지하며 실내·1인칭·전체 보기 규칙은 바꾸지 않는다.

## 검증

- 수정 전 실패하는 회귀 테스트를 확인했다. 벽 앞의 최종 카메라 여유가 있는데도 캐릭터가 숨겨지는 경우를 재현하며, 명시적 1인칭 숨김도 유지한다.
- `scripts/qa-v8-exit-avatar.cjs`: PC/모바일 Chromium에서 등불사장 문을 이동 입력으로 통과한 뒤 캐릭터 표시와 계속 걸을 때 표시 유지를 확인한다. 스크린샷은 `outputs/door-motion/exit-fixed-*.png`에 저장한다.
- 온라인 연결과 DB 쓰기를 차단한 브라우저 검증이다. 실제 iPhone Safari/GPU 및 운영 다중접속 부하는 별도 검증하지 않았다.
- 전체 Node 테스트 365개, production build, diff check 통과. PC 1000×760 및 모바일 390×844에서 퇴장 직후 표시와 이후 8프레임 이동 중 표시를 확인했고 페이지 오류는 0건이다. 소프트웨어 렌더러의 실행 시간은 실기기 FPS 보장이 아니다.
