# 누락 기능 복구·운영 배포

사용자의 ‘진행하고 배포해’ 요청으로 PR41의 걸이대 수정과 누락 기능 복구를 함께 운영 반영한다. 이번 요청은 이전 PR 전달만/클로드 배포 정책을 대체한다. 저장소 feelover7-ui/reading-community-app, Vercel 팀 ami18, 프로젝트 reading-community-app(prj_3JXKTzn7lGKmuNvyA3eUXorXX7eE), production/main을 확인했다. 다른 Vercel 프로젝트 설정은 변경하지 않는다.

## 복구

- 기존 걸이대 메시지 확인/수정과 등 걸기→점등→탑돌이·참배 연결(PR41)을 포함한다.
- 실제 법당 방석의 절하기 메뉴에 예불·칠정례, 법회·함께 읽기, 좌선1/3/5분을 연결한다. 기존 삼배/1·7·21·108배, 접지, 빈 방석 선택, 문턱 출입을 유지한다. 법회는 체험용 안내 글임을 표시하며 실제 스님의 법문으로 사칭하지 않는다.
- 예불문을 읽으며7배, 읽기는 직접 다음을 눌러 진행, 좌선은 선택한 시간과 들숨/날숨 안내를 표시한다. 수동 이동/중단/페이지 이탈 시 종료하고 창/채팅을 연 동안은 좌선 시간을 진행하지 않는다. 앉은 사람/방석을 가리지 않게 안내를 위에 배치한다.
- 108배 빠르게×2.5와 최고기록을 복구했다. 기존 최고기록을 읽고 현재 진행의 최대 값을 보존하며 오늘 총 절 횟수와 별도로 저장한다. localStorage만 사용하고 DB 기록을 만들지 않는다.
- 방명록/대화는 실시간 INSERT를 수신하고 열린 창/간편 대화는15초 재조회로 보완한다. 글id 단위 DOM을 유지해 초안·삭제 비밀번호·포커스를 보존한다. 늦은 조회 중 들어온 글/자기 삭제를 덮지 않으며 같은id를 중복 표시하지 않는다. 구독/타이머는 페이지 이탈 시 정리한다.
- 바깥 도량의 간편 대화 입력창과 Enter 열기를 복구했다. 기존 공용 createChat의 IME/중복 전송/실패 입력 보존을 사용한다. 확인된 전송만 입력을 지우고 기존 말풍선/공유 messages에 연결한다. 새 글 수신과 재조회 기록 전달은 별도id 추적으로 중복을 막는다.
- 소원등 목록은 공유 등과 초기/로컬 등을 합치고 내 등·등 모양을 표시한다. 로컬에서 같은 내용의 등 여러 개를 만든 경우도 보존한다. 공유조회 실패 때도 이 기기의 등 목록은 보여준다.

## 검증

- 전체 테스트144개와 빌드 통과. 기존 Three.js 번들 크기 경고 유지. 새 테스트는 타이머/분 경계, 구버전108기록, 좌선 접지, 실시간·조회 경쟁, 삭제/초안/포커스, 소원등 중복 병합, 간편 대화의 기록/재조회 전달을 포함한다.
- 독립 코드 리뷰에서 실시간 누락 후 재조회한 대화가 간편 창에 표시되지 않는 문제를 발견했다. 이미 캐시된 기록과 재조회 새 글의 전달 회귀 테스트를 RED→GREEN으로 고치고 전체 테스트 통과.
- Chromium PC800×700/모바일 모형390×844: 실시간 새 글/포커스·삭제 비밀번호·초안 보존, 공유+로컬 내 등, 간편 대화 실패 보존/확인된 전송, 걸이대 수정 이후 안내, 예불 시작/중단, 법회 전체 읽기, 좌선1·3·5분 시작/중단, 108배2.5배/최고기록 재접속 보존을 확인했다. 두 환경 pageerror0.
- 브라우저 전송/수신 검증은 API mock을 사용했다. 운영 DB에는 테스트 글·대화·소원등을 쓰지 않았다. 실제 iPhone GPU/다중 사용자 부하는 미검증이다.
- main 병합 시 Vercel Git integration의 production 배포를 확인하고, 운영 주소에서 쓰기 요청을 차단한 읽기 위주의 브라우저 검증을 진행한다. 배포 결과 URL/SHA/READY는 최종 전달에 기록한다.

시설 위치·방향·규모·생성 첫 화면·캐릭터·제작 순서는 유지했다. 새 라이브러리·조명·DB 스키마·통신 메시지 형식·운영 환경변수는 변경하지 않았다.
