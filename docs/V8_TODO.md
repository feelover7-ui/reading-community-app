2026-11-15 사용자 요청으로 보류. 이번 사용성 배포에는 포함하지 않는다.

- [ ] 승인 담당 관리자 이메일과 회원 명부 관리 위치 확인.
- [ ] 로그인 계정에 묶인 확인 신청·관리자 승인·반려·철회 절차 설계.
- [ ] 관리자 권한을 서버/DB에서 강제하고, 명부와 연락처는 일반 사용자에게 공개하지 않기.
