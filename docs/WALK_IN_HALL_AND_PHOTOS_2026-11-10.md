# 법당 걸어서 입장·공식 사진 수집

## 변경
- 법당 3층 연결문의 실제 문턱을 안쪽으로 걸어 넘으면 기존 5층 대법당 체험으로 바로 이동한다. 확인 모달을 없애고 Space·작업 버튼 대체 입장은 유지했다.
- 문 주변에 서 있거나 법당에서 복귀한 것만으로는 입장하지 않는다. 문 옆 통과, 바깥 방향 이동, 큰 좌표 이동, 대화 중 진입도 제외한다. 중복 이동을 막고 뒤로가기 캐시 복원 시 입력·입장 상태를 초기화한다.
- 건물·동상·구정탑 위치/방향, 도량 경계·길, 층 연결과 기존 내부 체험은 변경하지 않았다. 담장은 추가하지 않았다.
- 작업 도중 PR #37이 병합되어 최신 main 68c7559 위의 후속 PR로 전환했다.

## 사진 자료
공식 https://hanmaum.org/content/one_tour_01 부터 one_tour_09까지 실제 HTML에 연결된 원본 65점을 받았다. 사진·세부 이미지 64점과 조감도 1점을 구분했다. 수집 실패 0건, 원본 합계 17,570,176바이트. 출처·파일명·종류·SHA256·수집 시간은 `HANMAUM_PHOTO_MANIFEST_2026-11-10.json`에 기록했다.

별도 전달물은 `/workspace/reference-photos/hanmaum-photos-2026-11-10.zip`이며 오프라인 사진 목록, 분류·검색, 원본 출처 링크, 주요 12점 모음 이미지를 포함한다. 원본은 저장소·앱·배포용 텍스처에 넣지 않았다.

분류: 대법당·본존불·닫집 4점, 목탱화 18점, 선사 진영·세부 9점, 천장·단청·별화 8점, 칠보탑·지붕 3점, 구정탑·받침·도량 4점, 동상·심주석 14점, 기타 도량 세부 4점, 조감도 1점.

주요 사진 12점의 실제 픽셀을 모음 이미지로 확인했다. 0201에서 높은 단청 천장과 양옆 창, 중앙 넓은 바닥 및 본존불 전면을 확인했다. 0202·0203은 닫집과 금색 불단의 세부, 0501은 천장 격자·보·단청의 참고 자료다. 0601·0603에서 지붕 위 칠보탑과 검은 기와, 0701·0702에서 구정탑 받침과 주변 포장, 0801·0802에서 동상 받침·뒤 심주석과 주변 도량을 확인했다. 행사·야간 사진은 조명·장식이 상시 상태와 다를 수 있다. 사진만으로 실측 천장고나 정확한 평면 치수를 확정하지 않는다.
