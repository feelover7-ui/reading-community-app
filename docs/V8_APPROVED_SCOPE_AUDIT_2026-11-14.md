## 부분 구현

| 항목 | 실제 상태와 남은 차이 |
|---|---|
| 사진 기반 도량·법당·서산정 | 사진을 참고한 절차형 기하·재질이다. 실측 복원, 사진측량 모델, 정밀 후면 자료 반영은 아니며 2D 대체 화면은 이전 단순 장면이다. |
| 본원 | 1층·2층·3층·5층 선택 공간이 있다. 4층과 전 층 실내를 모두 복원한 구조는 아니다. |
| 동상·구정탑·칠보탑 설명 | 형상과 공식 링크/참고 갤러리는 있으나 개체별 근접 설명은 불균일하고 칠보탑 전용 설명 선택은 없다. |

| 채팅 | 실시간 채팅 자체는 존재한다. 요청했던 지속형 `마당 소식` 패널은 설계 문서만 있고 현재 짧은 표시+별도 대화창 구조다. |

|---|---|
| 자동 탑돌이 | 현재 v8은 표식을 따라 직접 세 바퀴 걷는 방식이다. 2026-11-11의 자동 한 바퀴+추가 바퀴 승인은 이전 경험에만 기록되어 있고 v8에는 유지되지 않았다. |

| 채팅 원점 재설계 | `docs/V8_CHAT_REDESIGN_2026-11-14.md`의 기획만 있으며 구현하지 않았다. |
| 4층 및 전 층 실내 | 장면·출입·상호작용 계약이 없다. |

## 운영상 확인하지 못한 것

- 실제 iPhone Safari와 해당 GPU에서의 3D 프레임, 문 통과, 조이스틱 조작
- 80대 기기의 동시 3D 렌더링과 한국 모바일망 지연. 기존 80개 시험은 릴레이 전송 클라이언트 시험이다.
- 현재 운영 DB에서 방명록/등 공유의 실제 쓰기·삭제 전체 흐름
- 사진과 실측 치수의 정밀 일치

따라서 “승인한 모든 항목이 현재 v8에 그대로 구현됐다”는 표현은 사용하지 않는다. 위 표의 구현·부분 구현·미구현 경계를 배포 보고에도 그대로 유지한다.
