# 등이 산다 — 심지와 서로 밝혀 주기

기획안의 두 번째 조각입니다. 걸고 끝나던 소원등에 시간이 흐르게 하고,
그 시간을 **다른 법우가 되돌려 줄 수 있게** 했습니다.

## 무엇이 달라지나

- 등 아래에 소원과 함께 **`9명이 밝혀 주었어요`**, **`심지 3일 남음`** 이 보입니다.
- 남의 등 앞에 서면 **`Space · 소원등 밝혀 주기`**. 한 번 누르면 그 등의 심지가 이틀 길어집니다.
- 심지가 줄면 등이 서서히 흐려집니다. 다 타도 **꺼지지는 않고** 흐리게 남습니다.
- 그래서 **이틀 뒤에 다시 올 이유**가 생깁니다. 내 등이 달라져 있습니다.

## 어떻게

| | |
|---|---|
| 혼자 두면 | 이레(`WICK_DAYS`) |
| 한 사람이 밝히면 | 이틀(`BLESSING_DAYS`) 더 |
| 아무리 받아도 | 서른 날(`MAX_WICK_DAYS`)까지 |

서버에는 **누가 어느 등을 밝혔는지만** 쌓습니다(`public.blessing`).
남은 심지는 `lanternLife.js` 가 건 날짜와 밝힌 사람 수로 계산합니다. 심지 컬럼이 없습니다.
그래서 시간이 흘러도 서버에 쓰는 일이 없습니다.

`unique(lantern_id, owner)` 라 한 사람이 같은 등을 거듭 밝히지 못합니다.
내 등은 내가 밝히지 않고, `id` 가 없는 시드 등(장식)도 밝힐 수 없습니다.

## 확인한 것

- `npx vite build` 성공, `node --test tests/*.test.mjs` **155 pass / 0 fail**
  (새 `tests/lantern-life.test.mjs` 6건: 이레에 걸쳐 타는 것, 밝히면 길어지고 상한에서 멈추는 것,
  날짜를 모르면 깎지 않는 것, 다 타도 안 꺼지는 것, 화면 문구, 내 등·중복 차단)
- 배포 전 로컬에서 실제 걸린 등 앞에 서서 `소원입니다 / 심지 3일 남음` 과
  `Space · 소원등 밝혀 주기` 확인. 시드 등(`모든 생명이 평안하기를`)에는 **안내가 안 뜸** — 맞는 동작입니다.
- 콘솔 오류 0.

## 아직 확인 못 한 것

- **`supabase/blessing.sql` 을 운영 DB에 실행하지 않았습니다.** 실행 전에는 밝힌 사람 수가
  늘 0이고 `밝혀 주기` 를 눌러도 올라가지 않습니다.
- 이 작업 폴더의 개발 서버는 운영 DB를 **읽습니다.** 그래서 쓰기(밝혀 주기)는 로컬에서
  누르지 않았습니다. 실제 쓰기는 배포본에서 확인해야 합니다.
- 심지가 여러 날에 걸쳐 실제로 줄어드는 모습은 날짜를 돌려 보지 않았습니다. 계산식만 시험했습니다.
