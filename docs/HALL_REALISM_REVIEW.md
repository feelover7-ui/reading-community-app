## 구현
- 단순 원통형 입상처럼 보이던 본존불을 결가부좌의 무릎/상체/팔/손/이목구비/육계와 연화좌대로 교체. 한 분만 모신다.
- 좌대 대 전체 높이 비율은 공식 2자/8자 설명을 참고한다. 게임 좌표는 실측이 아니다.
- 후불 목탱화의 기존 바퀴 장식을 제거. 세 부분 목판에 왼쪽 지옥계의 바위/군상, 중앙 성도/광명/수미산/연꽃/지구/등을 보인 수행자, 오른쪽 중생계의 군상을 추상적으로 그린 독자 제작 텍스처. 32고승은 작은 실루엣으로 표현한다. 실제 인물 초상이나 조각과 같지 않다.
- 닫집의 겹처마/금빛 테두리, 무광 금빛 재질, 법의 질감 추가.
- 천장 연화문/두 용을 뜻하는 순환 곡선과 오방색, 네 보, 빗반자, 창살 추가.
- 기존 좌복·충돌·출입·자동 구도/자유 시점·삼배·통신·모바일 PR #22 변경을 보존.
- 모바일은 법당 그림자를 끈다. 외부 다운로드/실시간 반사/후처리/새 라이브러리는 추가하지 않는다. 목탱화 1024×384와 천장512×512 캔버스 텍스처를 한 번 생성하며 매 프레임 다시 그리지 않는다.

## 정확도와 검증
- 본존불 손 모양, 표정, 법의, 닫집 단청, 목탱화 도상/양각 깊이, 실제 벽/창/수미단 치수는 사진 세부 대조가 필요하다. 현재는 사실감을 높이는 첫 시안이다.
- 특히 목탱화는 평면 텍스처+bump의 얕은 표면이며 실제 전체 입체 조각 복원은 아니다.
- 새 모듈/수정 장면의 JavaScript 구문 검사 PASS. 현재 환경에는 실행 터미널과 브라우저가 없다. 실기기 화면·FPS·발열 NOT RUN.
- Claude: npm run build, node --test tests/mobile-ui.test.mjs 및 기존 hall/camera 검사 후 /beopdang.html에서 가로/세로·최소/최대 줌·자동 구도·절·왕복을 확인한다. 공식 사진과 나란히 본 뒤 조형 비율을 조정한다.
