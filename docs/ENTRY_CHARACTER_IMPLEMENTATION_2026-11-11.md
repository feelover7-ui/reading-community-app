# 승인 첫 화면·캐릭터 구현

사용자가 통합 시안을 승인하고 구현을 요청했다. 기존 PR40의 최신 변경 위에 추가한다. 도량 시설 배치·방향·층수·제작 순서·탑돌이/참배/방명록 기능은 유지한다.

## 첫 화면과 입장

입구·등·탑·본원을 담은 생성 삽화와 한마음으로, 등을 밝히다 문구, 주요 입장 버튼 하나를 사용한다. 삽화는 실제 실행 화면/현장 사진이 아니며 하단에 입장 일러스트라고 표시한다. 실제 도량 모델이나 배치를 삽화에 맞춰 바꾸지 않는다. 배경은 WebP약189KB이며 게임 장면의 3D 텍스처로 쓰지 않는다. 시작 버튼을 누르기 전 전체 3D의 연속 렌더는 기존처럼 멈춘다. 초기화/폰트 대기 상한·WebGL 실패 및 다시 시도 경로는 유지한다.

처음에는 별명12자와 기본 모습만 고르고, 머리/옷 세부 선택은 접힌 더 꾸미기에서 선택한다. 기존 설정은 모두 유지한다. 설정창에 초기 포커스를 두되 가상 키보드를 강제로 열지 않는다. Tab/Shift+Tab이 summary를 포함해 설정창 안에 머문다. 닉네임/기본 모습 확정 전 presence에 참여하지 않는다.

입장하면 작업장 남문 안쪽의 안전한 자리에서 시작한다. 작은 첫 방문 안내는 등 만들기/탑돌이/법당/자유 탐방을 제공하며 모달로 이동을 막지 않는다. 직접 걷거나 다른 창을 열면 접힌다. 재방문은 저장된 별명과 모습으로 바로 이어서 들어가며 첫 화면의 이름·모습 바꾸기로 수정할 수 있다. 제작 진행은 보존하고 다음 작업대 안내는 현재 단계를 따른다. 이전 소리 선택이 없을 때만 기본을 꺼짐으로 정하고 이미 저장한 선택은 존중한다.

## 캐릭터

characterStyle.js로 바깥과 법당의 얼굴·손·조끼·머리를 공유한다. 기존 전체 키를 거의 유지하면서 머리를0.85배/중심높이0.69로 조절해 약4등신 비례로 만들었다. 귀·코·눈썹·짧은 미소, 엄지가 있는 손바닥, 조끼 주머니/여밈을 더하고 몸통과 신발의 모서리를 둥글게 했다. 새 방문자의 기본 조끼는 잔잔한 녹색이다. 기존 사용자가 고른 색/머리는 바꾸지 않는다.

손에 든 등은 머리 위가 아니라 몸 앞 두 손 사이에 위치하며 움직이는 동안 팔을 크게 흔들지 않는다. 동작 줄이기에서는 등의 흔들림을 멈춘다. 법당에서도 저장한 머리 모양/색과 옷·바지색을 이어 쓴다. 새 얼굴/옷 기하는 재질별로 병합하고 임시 기하는 해제한다. 기존 관절·삼배·접지·appearance 키·presence 프로토콜은 보존한다. 생성 시안의 직물·머리카락 미세 질감을 그대로 재현한 외부 고해상도 모델은 아니며 경량 기하로 구현했다.

## 검증

node --test tests/*.test.mjs 131개 통과. 머리/손 치수·저장 모습 변환·머리모양/옷별 바지색, 기존 삼배101단계 접지/이마·정강이·합장 테스트 포함. 빌드 통과, 기존 Three.js 번들 크기 경고 유지.

독립 검토에서 법당의 머리/바지색 불일치와 초기 Shift+Tab 이탈을 발견해 수정했다. 모습 변환 테스트와 키보드 브라우저 점검에서 수정 전 실패/수정 후 통과 확인.

PC1200×900/모바일 모형390×844의 새 방문→최소 설정→안내 이동/중단, 재방문 시 꾸미기 생략, 이름/머리 수정, 법당 삼배와 방석 높이를 확인했고 두 환경 모두 pageerror0이었다. 실제 iPhone GPU·운영 DB 쓰기·다중 사용자 부하는 미검증이다. 새 의존성·빛·후처리·사진 텍스처·운영 DB/배포/병합 변경은 없다.
