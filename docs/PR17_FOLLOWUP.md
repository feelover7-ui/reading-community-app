## 검증

- 사용 가능한 로컬 터미널이 없어 Node/npm/workerd/브라우저를 직접 실행하지 못했다.
- 도구 내 V8에서 import/export를 제거하고 같은 함수를 실행: 기존 방 로직16 + #18 회귀8 + 후속 relay4 + 안내걷기/카메라4 = 32개 PASS.
- URL/UTF-8/UUID/storage/socket/timer 등 환경 API는 테스트 대역으로 주입했다. 정식 node --test나 실제 WebSocket 80명 시험과 다르다.
- 새 안내 원 반경4의 360개 위치를 기존 solid 배열과 캐릭터 네 모서리에 대조: 막힌 표본0.
- 가로/세로/desktop 세 해상도 × 입구/좌우 좌복 네 위치에서 불단·캐릭터의 기준점이 FOV 안에 드는 수학 검사를 통과했다. 실제 가림/영상 품질 검증은 아니다.
- 변경 JavaScript 문법 검사 통과. Vercel preview 빌드 결과는 PR에 연결된 배포를 확인한다.
