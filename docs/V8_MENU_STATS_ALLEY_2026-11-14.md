# v8 모바일 메뉴 · 능력치 · 골목 (2026-11-14)

사용자 요청 세 가지입니다. 기준 main `9a8283c`.

## 1. 모바일 메뉴가 너무 길었습니다

> "모바일에서 메뉴버튼 누르면 뭐가 너무 많아 이곳에서 없애고, 합창 반배 채팅은 빠지게해줘"

`usability.js` 의 `m-sheet` 는 묶음이 넷이었습니다.

| 묶음 | 내용 | 지금 |
| --- | --- | --- |
| **이곳에서** | 그 장소의 활동 전부(`#sceneToolsList` 복제) | **뺌** |
| **인사** | 합장 · 반배 · 채팅 | **뺌** |
| 메뉴 | 도량 · 일지 · 캐릭터 · 배낭 · 둘러보기 | 그대로 |
| (이름 없음) | 1인칭 보기 · 소리 · 도움말 · 설정·저장 | 그대로 |

- 장소 활동은 이제 **걸어가서 작업 단추**로 합니다. 화면 아래 안내(`#mGoal`)와
  바닥 눌러 걷기는 그대로입니다.
- **대화는 화면의 💬 단추(`#mChat`)로 뺐습니다.** 메뉴에서만 빼면 휴대폰에서
  대화할 길이 아예 없어집니다(Enter 가 없으므로). 작업 단추 위, 오른손 자리입니다.
  누르면 어제 만든 **한 줄 입력**만 열리고 세계는 멈추지 않습니다.
- **합장·반배는 휴대폰에서 사라집니다.** PC 에는 그대로 있습니다. 다시 필요하면
  💬 옆에 한 줄로 둘 수 있습니다.

## 2. 능력치를 없앴습니다

보이던 곳을 전부 뺐습니다.

- 캐릭터 창의 `여섯 가지 활동 능력치` 묶음 — 육각 레이더, 숫자 칩, 설명문.
  두 칸 격자가 한 칸이 되도록 `.char-layout.solo` 를 뒀습니다.
- 활동을 마친 결과 창의 `집중 +1.2 · 정성 +0.8` 줄.
- 문구: 캐릭터 창 부제, `#profileCard` 의 읽어 주는 이름, 도움말, 외관 창 안내,
  배낭의 `능력치에 반영 중` 꼬리표.
- 쓰지 않게 된 `statChart()` 레이더 그리기 함수도 지웠습니다.

**저장 구조는 건드리지 않았습니다.** `store` 는 `training` 값을 그대로 읽고 씁니다.
지우면 이미 저장된 기록이 검증에서 걸려 들어오지 못합니다. 화면에서만 뺐습니다.

## 3. 횡단보도만 건너지 않아도 됩니다

> "횡단보도만 건너게 안해도돼"

`street` 층의 걷는 구역에서 골목(x 29.7~36.5)은 **z 19.6~21.9 한 칸**만 열려 있었습니다.
양쪽 보도와 같은 범위(z −16~26)로 넓혔습니다. 이제 골목 어디서나 건넙니다.
횡단보도 그림은 그대로 있습니다. 골목 밖은 여전히 막혀 있습니다.

## 확인한 것

로컬 dev(휴대폰 390×844, 2배율, 2D 대체 렌더러)에서 봤습니다.

- 메뉴 묶음이 `['메뉴']` 하나. `mSheetHere`·`mSheetSocial` 없음.
- 💬 보이고, 누르면 한 줄 입력 열림 · `paused:false` · 초점 `quickChatInput`.
- 캐릭터 창에 `능력치` 글자 없음, 레이더 없음, 숫자 칩 없음.
- 골목 걷기 판정: 횡단보도 자리 ✓ / 가운데 ✓ / 아래쪽 ✓ / 중간 ✓ / 골목 밖 ✗.
- 시험 245 + 워커 43 통과, 빌드 통과.

## 확인하지 못한 것

- **실기기 손가락 조작.** 이 컨테이너는 3D 가 약 3fps 라 2D 대체 렌더러로 봤습니다.
  💬 단추가 엄지에 닿는 자리인지, 작업 단추와 안 겹치는지는 실제 폰에서 봐야 합니다.
