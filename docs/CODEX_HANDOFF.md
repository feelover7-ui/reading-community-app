## 최신: 작업장만 본관 가까이 이동
사용자가 ‘등불사 작업장이 너무 멀어 가까이 붙여’라고 요청했다. 본원 내부·탑·동상·3층 문·북쪽 위 방향은 유지한다. 작업장 건물·앞마당·충돌·도착점만 동일 WORKSHOP_OFFSET으로 평행 이동하며 크기와 회전은 보존한다. 본관 동쪽 외벽과 작업장 서쪽 외벽 사이3게임단위 간격을 둔다. 기준 사진의 원래 작업장 좌표와 약209m 실제 거리 정보는 REFERENCE_WORKSHOP에 보존하고, 체험 배치에서는 간격을 줄였다고 표시한다. 이전 ‘모든 지점 거리축약 없음’ 규칙의 작업장 부분만 최신 요청으로 대체한다. main #26의 anyangSite.js/도량 건물 추가는 보존하고 기존 PR #22에 함께 반영한다.
