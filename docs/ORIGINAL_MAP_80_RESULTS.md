계획의 네 갈래 중 **렌더링(3장)** 과 **통신 구조(2장)의 코드·단위 시험**을 구현했습니다.

  같은 기계에서 잰 상대 비교로만 읽어 주세요.
- 측정 화면 900×620, 개발 빌드, 등불사장 트인 마당(18,20)에서 북쪽을 보고 측정.
- Cloudflare 자격 증명과 `wrangler` 가 이 환경에 없습니다(`which wrangler` 없음, 관련 환경변수 0개).

## PASS

### 1. 같은 장면 80명 캐릭터 표시 (계획 3장)

`createPeerLayer` 를 다시 썼습니다. 가까운 16명은 관절 모델, 나머지는 geometry/material 을
공유하는 인스턴스 몸체로 그립니다. 멀다고 사람을 지우지 않고 화면 밖만 건너뜁니다.

| 가짜 접속자 | fps | 그린 사람 | 관절 | 인스턴스 | draw calls | geometries |
|---|---|---|---|---|---|---|
| 0 | 7.23 | 0 | 0 | 0 | 340 | 230 |
| 20 | 6.01 | 20 | 16 | 4 | 583 | 350 |
| 40 | 5.38 | 40 | 16 | 24 | 581 | 349 |
| 80 | 5.24 | 80 | 16 | 64 | 585 | 351 |

- 80명 전원에 몸이 붙습니다(`drawn 80`, `offscreen 0`). 40명으로 줄여 통과시키지 않았습니다.
- 20명에서 80명으로 가는 동안 draw call 이 583 → 585 로 거의 그대로입니다. 늘어난 60명이
  인스턴스 3개 안에 들어가기 때문입니다. 같은 구간에서 fps 는 6.01 → 5.24 입니다.
- 0명 → 20명 구간이 제일 비쌉니다. 관절 모델 16개가 draw call 을 243개 늘립니다.
- 먼 사람도 색·방향·절 상태가 보입니다. 경계에서 모델이 떨리지 않게 들어올 때 9칸,
  나갈 때 11칸으로 기준을 다르게 뒀습니다.
- 이름표는 관절 모델(가까운 16명)에만 붙입니다. 캐릭터 수는 줄이지 않았습니다.

### 2. 자원이 늘어나지 않음

80명을 넣고 비우기를 6회 반복한 뒤:

- geometries 351 → 351, textures 24 → 24. 콘솔 오류 0건.
- 공유 geometry/material 은 레이어를 버릴 때(`destroy`) 한 번만 해제합니다.

### 3. 통신 프로토콜·방 로직 단위 시험 15개 전부 통과

`cd workers/lantern-room && npm test` → `# tests 15 / # pass 15 / # fail 0`

검사한 것: 4KiB 상한과 바이너리 거절, **한글을 글자 수가 아니라 UTF-8 바이트로 재기**,
hello 의 버전·이름·외형·장면 검사, pose 의 유한·경계·속도·동작 검사,
같은 epoch 의 역순·중복 seq 버리기와 재시작 시 기준 초기화, 토큰 버킷,
재접속 full jitter(1~30초), 보정 750ms 상한, **80명 수용과 81번째 거절(기존 사람 안 밀어냄)**,
observer 1명이 79명을 보는 것, 끊김 45초 유예와 유예 안 복귀 시 중복 없음, 유예 만료 뒤 제거,
바뀐 사람만 묶어 보내고 변화 없으면 알람 멈추기, 경계 밖·과속 좌표를 저장하지 않기.

### 4. 기존 기능 회귀 없음

- `npm run build` 통과.
- 세 화면 + 독서 홈: 걷기, 둘러볼 곳 6곳, 좌복 절 5종, 삼배 진행. 콘솔 오류 0건.
- 실제 접속자 2명(로컬에서 운영 Supabase 연결): 등불사장에서 서로의 인형·이름표가 보이고
  화면 밖으로 나갔다 돌아와도 유지. 대법당에서 한쪽이 스물한 배를 시작하면 상대 화면에서도 몸이 낮아짐.
- 기본 통신 경로는 그대로 Supabase 입니다. relay 어댑터는 `localStorage` 깃발이 있을 때만 고릅니다.

### 5. 휴대폰 해상도 상한

`hover:none and pointer:coarse` 인 기기는 devicePixelRatio 상한을 1.25 로 시작합니다(계획 `mobileInitialDprCap`).
