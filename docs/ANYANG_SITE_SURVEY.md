# 안양 본원 도량 배치 — 어떻게 읽어서 어떻게 옮겼나

2026-11-09, Claude. 사용자 요청: **"법당만 들어가게. 나머지는 그대로 구현. 가상공간에서 도량을
둘러보게 하고 싶다. 최대한 비슷하게."** 그리고 위성을 직접 읽어도 좋다는 허락을 받았습니다.

## 1. 자리 찾기

공개된 OpenStreetMap 에 등록된 점은 `37.4216507, 126.9086436` 인데 **길 건너편**을 가리킵니다.
카카오 장소검색의 `한마음선원 안양본원` 이 맞습니다.

```
경기 안양시 만안구 경수대로 1282 (지번 석수동 101-60)
37.4216180, 126.9085209
```

OSM 에는 이 도량의 **건물 윤곽이 하나도 없습니다.** 점 하나뿐입니다.
Overpass·VWorld·네이버 지도는 이 컨테이너에서 닿지 않습니다. 카카오맵만 열립니다.

## 2. 위성에서 잰 것

카카오 스카이뷰(국토지리정보원 항공영상)를 레벨 1 로 띄우고, 기준점에서 20m 간격으로
눈금을 찍어 그 위에서 읽었습니다. 그때 배율이 **1m = 7.93px** 였습니다. 북쪽이 위입니다.

본관(법당)의 기와지붕 네 귀퉁이를 읽은 값 (기준점에서 동쪽+, 북쪽+ 미터):

| 귀퉁이 | 동 | 북 |
| --- | --- | --- |
| 북 | 40.1 | −3.6 |
| 동 | 56.9 | −23.1 |
| 남 | 22.8 | −43.9 |
| 서 | 10.0 | −27.4 |

여기서 나온 것:

- 본관은 약 **27m × 39m**
- 정북에서 **시계방향 약 49도** 돌아앉아 있습니다. 경수대로를 따라 도량 전체가 같은 각도입니다.
- 도량 전체는 대략 **70m × 90m** 입니다.

## 3. 위성으로 못 한 것

- **스카이뷰는 수직 사진이 아닙니다.** 조금 기울어져 찍혀서 높은 건물은 지붕이 옆으로 밀려 보입니다.
  본관 같은 5층 건물은 지붕 외곽과 실제 바닥 자리가 다릅니다. 위 치수는 **지붕 기준**입니다.
- 본관 말고는 **어느 지붕이 어느 건물인지 위성만으로 가릴 수 없습니다.** 주변이 빽빽한 주택가라
  담 안팎의 경계도 분명하지 않습니다.

그래서 나머지 건물은 **공식 선원 안내도(조감도)의 범례와 앞뒤·좌우 관계**로 놓았습니다.
조감도는 사선 투시라 거리가 왜곡돼 있어, 두 자료를 그대로 겹칠 수 없습니다.

## 4. 결론: 무엇이 잰 값이고 무엇이 옮긴 값인가

| | 근거 |
| --- | --- |
| 본관의 크기·방향, 도량 전체 크기 | **위성에서 잼** |
| 건물 이름, 층별 용도, 번호 | **공식 조감도 범례** |
| 본관 외 건물의 자리 | 조감도의 배치를 위성 축에 맞춰 **옮김** |
| 구정탑(22,41)·동상(8,32)·법당(32,34) 타일 좌표 | 기존 값 유지 (탑돌이·법당 문이 걸려 있음) |

**실측 지도가 아닙니다.** 걸어 다니기 위한 게임용 배치입니다.
타일 한 칸은 약 2m 로 잡았고 도량 영역은 x 1~48, y 26~68 입니다.

이미지는 저장소에 복제하지 않았습니다. 숫자만 옮겼습니다.

## 7. 아직 안 한 것

- **실기기 확인.** 이 컨테이너는 소프트웨어 렌더라 프레임 수를 쓸 수 없습니다.

- 조감도에서 `심주관·어린이법당·별관·원당·요사채` 를 뺐던 이전 규칙은 이번 요청으로 뒤집혔습니다.
