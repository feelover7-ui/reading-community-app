# v8 문화회관 출입문과 이동 지연 수정

## 원인과 변경

- 등불사장 내부에는 `backCampus` 자동 퇴장 지점만 있었고 실제 출입문 메시가 없었다. 그 좌표 (0, 16.3)에 열린 유리문·문틀·문턱·양면 안내판을 배치했다. 기존 도량 배치는 유지한다.
- 문 가운데는 비워 두고 문기둥만 충돌 처리한다. 자동 퇴장 반폭은 2.3으로 문 폭에 맞춘다. 중앙에서 2칸 벗어나도 통과하며 문 바깥 3칸 위치에서는 발동하지 않는다.
- 카메라는 캐릭터를 충돌 대상에서 제외하면서도 모든 메시를 먼저 정밀 검사했다. v7 스킨 메시가 추가되면서 이 불필요한 계산이 커졌다. 실내 기본 카메라와 실외 가림 방지 카메라 모두 `cameraHits()`를 사용한다. 로컬·원격 캐릭터, 스킨 메시, 보이지 않는 가지, cameraIgnore 가지, 스프라이트를 삼각형 계산 전에 제외한다. 정적 벽 충돌은 유지한다.

## 측정과 검증

- 실제 v7 남성 메시를 사용한 격리 CPU 진단, 카메라 12회 호출: 수정 전 644.803ms 중 캐릭터 raycast 635.661ms/12회. 수정 후 2.953ms, 캐릭터 raycast 0회. 최종 카메라 위치는 동일했다. 전체 게임 FPS나 실제 아이폰 성능 수치가 아니다.
- 회귀 시험: 캐릭터의 raycast 함수가 호출되지 않음, 벽 앞 카메라 당김과 복구, 숨긴 벽 및 제외된 부모 가지 처리, 문 개구부와 넓은 자동 통과 범위.
- 브라우저 검증 스크립트: `scripts/qa-v8-door-motion.cjs`. PC 1000×760, 모바일 크기 390×844 Chromium에서 실제 문 렌더링, 개구부 보행 가능, 캐릭터 raycast 0회, 앞쪽 이동 입력으로 도량 자동 퇴장을 확인한다. REST 쓰기는 차단한다.
- 스크린샷과 실행 결과는 로컬 `outputs/door-motion/`에 저장한다. 실제 iPhone Safari/GPU, 운영 DB 쓰기, 다중 접속 부하는 검증 범위 밖이다.
- 문은 기존 게임 내부에 추가한 시각적 출입구이며 사진으로 확인한 실측 복원이 아니다. 일부 실외 수관 옆 카메라 높이 변화와 기기별 렌더링 부하는 별개로 남아 있다.

최종 확인: `node --test tests/*.test.mjs` 356/356 통과, `npm run build` 통과(기존 Three.js 번들 크기 경고), `git diff --check` 통과. PC·모바일 크기 브라우저 모두 문 옆쪽 x=2에서 실제 이동 입력으로 자동 퇴장, pageerror 0. 카메라 24회 호출 시 스킨 메시 raycast 0회.
