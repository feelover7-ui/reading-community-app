# 코덱스 맵을 본 도량으로 (2026-11-09)

사용자 요청: **"코덱스맵으로 기능 구현해서 합치자."** 다섯 가지를 받았습니다.

1. 클로드 맵의 등불사 작업장을 옮겨 오고 **시작 지점도 작업장으로**
2. **법당에 들어가게** (클로드 맵 참고)
3. **맵을 사각형으로**, 반듯하게 보이도록 시점 다듬고 빈 곳은 클로드 맵 분위기로
4. **등불사장 → 법당**, **등불사장 → 도량탑** 길
5. 나머지 클로드 맵 기능 가져오기. **건물은 더 늘리지 않기**

그리고 클로드 맵은 지우지 말고 시작 화면에 작게 두기.

---

## 한 일

### 반듯하게 (3)

본관은 정북에서 36.4도 기울어 앉아 있어 사진 그대로 두면 화면에서 비스듬했습니다.
같은 사진의 본관 지붕 긴 변을 화면 가로축에 맞추도록 **도량 전체를 한 각도만큼 돌렸습니다**
(`SITE_YAW`, `pixelToSite` 한 곳에서). 한 점만 옮긴 것이 아니라 전부 같은 각도로 돌렸으므로
서로의 자리 관계는 그대로입니다. 북쪽은 더 이상 화면 위가 아니고 나침반 바늘이 돌아간 북쪽을 가리킵니다.

### 사각형 마당 (3)

사진에서 읽은 들쭉날쭉한 담 윤곽 대신 **네모난 마당**(`YARD`, 40×42 단위 ≈ 100m×105m)을
걷는 범위로 씁니다. 담을 둘러 세웠고, 원래 윤곽은 근거로 남겨 바닥 무늬로만 보여 줍니다.

### 비탈길과 길 (3·4)

높은 마당(도량탑·동상)은 본관 3층과 같은 높이입니다. 지금까지는 장소 버튼으로만 올라갈 수 있었습니다.
**서쪽에 비탈길을 놓아 걸어서 올라갑니다.**

```
작업장 문 → (본관 남쪽) → 서쪽 길 → 비탈길 → 높은 마당 → 도량탑 / 법당 문
```

사진에서 실제 계단의 단차를 읽지 못했기 때문에 계단이 아니라 비탈입니다.
**실제 계단의 자리나 형태가 아니라 걸어 올라가기 위한 장치입니다.**

### 탑 둘레 마당 (5)

탑돌이는 반지름 4 로 한 바퀴를 도는데, 사진에서 읽은 높은 마당은 탑 동쪽이 1.2 밖에 안 남아
한 바퀴가 돌아지지 않았습니다. 그래서 **탑 둘레에 걸을 수 있는 둥근 마당**(반지름 5.6)을 두었습니다.
이것도 사진에서 읽은 윤곽이 아니라 탑돌이를 위해 둔 자리입니다.

### 가져온 기능 (1·2·5)

| | 상태 |
| --- | --- |
| 시작 지점을 등불사 작업장 앞으로 | 됨 |
| 법당 문에서 `살펴보기` 두 번 → `beopdang.html` | 됨 |
| 구정탑 탑돌이 세 바퀴 (`tapdori.js` · `orbitProgress.js` 그대로) | 됨 |
| 대행선사 동상 앞 삼배 (`three3d.js` 의 `bowPose`) | 됨 |
| 미니맵 (사각형 마당·길·비탈·탑 마당) | 됨 |
| 석등·등줄·나무로 빈 곳 꾸미기 | 됨 |
| 건물 추가 | **안 함** (요청대로 본관·작업장 둘뿐) |

탑돌이 바퀴 수는 클로드 맵과 같은 `orbitProgress` 가 탑 중심의 **실제 이동 각도**로 셉니다.
제자리 회전이나 순간이동은 세지 않고, 방향을 누르면 멈추며 돈 만큼만 남습니다.

### 시작 화면 (6)

도량을 큰 카드로 내놓고 **예전 클로드 맵은 아래 작은 줄**로 두었습니다. 지우지 않았습니다.

## 아직 안 옮긴 것

**등 만들기 전체가 아직 클로드 맵에만 있습니다.** 네 개의 작업대(골조·한지·채색·전기),
반장 법우와의 대화, 마당 걸이대에 소원등 걸기, 장엄등 점등, 오늘의 소임 목록이 그렇습니다.
이것들은 `campusScene.js` 한 파일에 그 맵의 타일 좌표·DOM·저장 구조와 함께 묶여 있어서
옮기려면 그 절반을 다시 쓰는 일이 됩니다. 이번에는 손대지 않았습니다.

작업장도 **위성사진에서 읽은 콘크리트 건물 그대로**입니다. 안은 만들지 않았습니다.

배경음악, 다른 접속자, 한 줄 이야기도 아직 코덱스 맵에는 없습니다.

## 표현하지 않는 것

도량의 자리와 거리는 **사진 판독에 따른 근사값**입니다. 비탈길·탑 둘레 마당·사각형 담은
걸어 다니기 위해 둔 것이고 실제 계단·마당·담의 자리가 아닙니다. 실측 지도가 아닙니다.
