# 코덱스 맵을 본 도량으로 (2026-11-09)

사용자 요청은 두 묶음입니다.

**첫 번째** — "코덱스맵으로 기능 구현해서 합치자" (앞선 작업, PR #28 로 반영됨)

**두 번째** — 이번 작업

> 1. 등 만들기 다 옮겨. 등불사장 콘크리트 건물로 하지 말고 클로드맵에 있는 거 가져와.
>    법당 건물 모양은 그대로 두되, 법당 내부 들어가게 해.
> 2. 등불사 작업장도 본원 3층 높이로 맞춰서 구정탑이랑 이어지게 해.
>    작업장을 좀 더 멀어지게 하고 길을 만들어 구정탑 탑돌이 범위랑 겹치지 않도록.
>    탑돌이 돌던 사람도 그대로 옮기고 탑돌이 기능도 구현할 것.
> 3. 서쪽 계단은 없애.
> 4. 위성지도 참고해서 좀 더 다듬을 수 있으면 다듬어 봐. 조경이나 길 등등.

## 1. 등 만들기를 통째로 옮겼습니다

### 코드를 복사하지 않고 한 곳으로 모았습니다

등 만들기는 `original/campusScene.js` 한 파일(892줄) 안에 그 맵의 타일 좌표·DOM 과 함께
묶여 있었습니다. **두 맵이 같이 쓰도록 꺼냈습니다.**

| 새 파일 | 안에 있는 것 |
| --- | --- |
| `src/deungbul/lanternCraft.js` | 2D 등 그림(`drawLantern`·`shapePath`·`makePreview`·`SHAPES`/`COLORS`/`PATTERNS`), 네 작업대 흐름, 걸이대, 장엄등, 반장·법우·스님 대화, 오늘의 소임 목록 |
| `src/deungbul/lanternCraft.css` | 등 만들기 창·말풍선·오늘의 소임 꾸밈 |
| `src/deungbul/workshopYard.js` | 작업장 안의 3D — 나무 바닥·담·기와·네 작업대와 소품·걸이대·석등·청년회 장엄등 |

화면마다 다른 것(저장, 말풍선, 소리, 공유)은 `createCraft(host)` 의 `host` 로 받습니다.
`campusScene.js` 는 자기 안에 있던 그 코드를 **지우고 이 모듈을 가져다 씁니다.**
두 맵의 등 만들기는 이제 같은 코드이고, 저장 키도 `hanmaum-campus-v2` 로 같습니다.

### 작업장은 클로드 맵의 작업장입니다

위성사진에서 읽은 **콘크리트 건물(태양광 패널 얹은 상자)을 없앴습니다.** 대신 클로드 맵과 같은
**담을 두른 열린 마당**입니다. 나무 바닥 위에 골조 → 한지 → 채색 → 전기 네 작업대가 왼쪽부터
놓이고, 남쪽에 소원등 걸이대, 남서쪽에 청년회 장엄등, 석등 셋이 있습니다. 서쪽 가운데가 문입니다.

안으로 **걸어 들어갑니다.** 문 앞에서 `살펴보기` 를 누르면 안내창이 뜨고, 한 번 더 누르면 들어갑니다.

### 법당

법당 건물의 모양은 건드리지 않았습니다. 법당 문 앞에서 `살펴보기` 를 두 번 누르면
**기존 대법당 화면(`/beopdang.html?from=codex`)** 으로 들어갑니다. 나오면 법당 문 앞에 섭니다.

> 그 브라우저에 이름과 모습이 없으면 대법당 화면이 맵 선택 화면으로 돌려보냅니다.
> 기존 규칙 그대로이고 이번에 바꾸지 않았습니다.

## 2. 작업장을 3층 높이로, 더 멀리, 길로 잇기

- **작업장이 마당과 같은 높이**가 되었습니다. 마당 전체가 본관 3층 바닥 높이(`YARD_Y = 4`)입니다.
- **더 멀어졌습니다.** 작업장 문에서 구정탑까지 **15.5칸(약 39m)** 입니다. 전에는 8칸이었습니다.
  작업장은 북동쪽으로 옮겼고 크기와 회전은 그대로입니다.
- **길이 탑돌이 범위를 밟지 않습니다.** 길은 탑 북쪽으로 돌아갑니다.

```
작업장 문 → (탑 북쪽으로 돌아) 갈림길 → 구정탑 / 법당 문 / 동상
```

`tests/codex-yard.test.mjs` 의 `길은 탑돌이 범위와 겹치지 않는다` 가 모든 길 꼭짓점이
탑 중심에서 `ORBIT_RADIUS + 0.9` 보다 멀리 있는지 봅니다.

### 탑돌이 돌던 사람

클로드 맵의 `WALKERS` 를 옮겼습니다. 두 법우가 반지름 2.2칸과 2.9칸으로 탑을 계속 돕니다.
동작 줄이기 설정에서는 멈춰 섭니다.

### 탑돌이

`tapdori.js` 의 `advanceGuidedOrbit` 과 `orbitProgress.js` 를 그대로 씁니다. 바퀴 수는 탑 중심의
**실제 이동 각도**로 세고, 제자리 회전이나 순간이동은 세지 않으며, 방향을 누르거나 장소 버튼을
누르면 멈추고 돈 만큼만 남습니다. 반지름은 2.6칸(약 6.5m)입니다.

## 3. 서쪽 계단(비탈)을 없앴습니다

`RAMP`·`onRamp`·`rampHeight` 와 그 그림·길을 모두 지웠습니다.
**마당 전체가 한 높이**라서 오르내릴 곳이 없습니다.
`tests/codex-yard.test.mjs` 가 마당 안을 훑어 높이가 한 값인지 봅니다.

> 실제 도량의 단차가 아니라, 걸어 다니기 위해 한 높이로 고른 것입니다.

---

## 4. 사람 크기와 조경

### 사람 크기를 도량 축척에 맞췄습니다

도량은 1칸 = 2.5m 로 그리는데 사람만 1칸 = 1m 로 그려서, **사람이 본관 한 층보다 커 보였습니다.**
사람을 0.4배(0.68칸 ≈ 1.7m)로 줄이고 걷는 속도·카메라 거리도 같이 줄였습니다.
작업대 소품도 같은 0.4 축척이라 사람과 작업대의 크기가 맞습니다. 동상도 0.4 로 맞췄습니다
(구정탑은 전부터 0.4 였습니다).

### 조경

담 안쪽을 따라 나무 **91그루**를 두르고 가운데는 드문드문 두었습니다. 길·탑돌이 길·문 앞·
장소 버튼 자리는 비워 둡니다. 나무 자리는 `sitePreviewData.js` 의 `GARDEN_TREES` 한 곳에서
정하고 충돌도 같이 관리합니다. 위성사진에서 읽은 녹지(`PLANTING`)와 담 윤곽(`PRECINCT`)은
그대로 두고 바닥 무늬로 씁니다.

길에 돌 이음새를 얹고, 걷는 동안에는 배치도 설명띠(`#legend`·`#info`)를 감춰
오늘의 소임 목록과 겹치지 않게 했습니다.

## 아직 안 옮긴 것

- **다른 접속자**(Realtime presence), **한 줄 이야기**, **배경음악**은 아직 클로드 맵에만 있습니다.
- 코덱스 맵에서 만든 소원등은 **이 브라우저에만 저장**됩니다. 공유 저장(Supabase)에 쓰지 않습니다.
  클로드 맵은 전처럼 공유 저장을 씁니다. 같은 저장 키를 쓰므로 내가 만든 등은 두 맵에서 같이 보입니다.
- `deungbul.html` 안에 남아 있는 등 만들기 CSS 는 `lanternCraft.css` 와 내용이 겹칩니다.
  돌아가는 화면의 인라인 스타일을 걷어내는 일은 따로 해야 합니다.

## 표현하지 않는 것

도량의 자리와 거리는 **사진 판독에 따른 근사값**입니다. 사각형 담, 탑 둘레 마당, 한 높이 마당,
작업장 안의 배치, 나무 자리는 걸어 다니기 위해 둔 것이고 실제 담·마당·단차·작업장 내부·조경의
자리가 아닙니다. **실측 지도가 아닙니다.** 작업장 주소(삼막로 23 · 석수동 93-1)는 사용자가
알려 준 것이고, 그 건물의 외관·입구는 확인하지 않았습니다.
