# v6: 예전 2D 등불사장 복원

사용자가 도량 탐방이 붙기 전의 2D 등불사장으로 돌아가고 `v6.html`로 배포하도록 요청했다.

## 복원 기준

- 원본: Git `5e67b2c`의 `deungbul.html`, `src/deungbul/game.js`.
- Canvas 2D 등불사장과 그 마당만 제공한다. 현재 v8·도량 건물 배치는 변경하지 않는다.
- 원래의 이름/캐릭터 선택, 작업대, 골조→한지→채색→전기·발원, 등 걸기·점등, 방명록·대화를 복원한다.
- 기존 로컬 저장 키를 유지한다. 기존 공유 등·방명록 API와 데이터베이스도 유지한다. 인증·회원 승인 기능은 보류 상태다.

## 최소 호환 수정

- Vite에 `/v6.html` 진입점을 추가하고 게임을 `src/v6/game.js`에 분리한다.
- 공유 API는 현재 모듈을 재사용한다. v6은 명시적으로 Supabase Presence를 선택해 원본의 입장 이벤트·뒤늦게 접속한 사람의 점등 동기화를 보존한다. 다른 게임의 기본 relay 선택은 바꾸지 않는다.
- 한글 키보드에서도 물리 WASD 키로 이동한다. 버튼을 누른 뒤 이동 키로 캔버스 초점을 회복한다. 입력창의 키 입력은 가로채지 않는다.
- 페이지를 떠날 때 Presence를 정리하고 브라우저 뒤로가기 캐시 복귀 시 다시 연결한다.
- Supabase가 없는 환경은 로컬 등 만들기/저장을 제공하고 공유·방명록 제한을 안내한다.

## 검증

- `tests/v6-presence-transport.test.mjs`: 명시적 Supabase 선택, 점등 메타데이터, 기존 relay 기본 동작, 로컬 폴백.
- `scripts/qa-v6-classic.cjs`: 운영 쓰기를 차단한 PC·모바일 실제 브라우저 제작/걸기/점등/저장 복구와 입력 검사.
- 실제 iPhone 하드웨어 및 운영 DB 쓰기 시험은 자동 브라우저 시험과 구분한다.

검증 결과: 전체 Node 테스트 401개 통과, Vite 빌드 성공. Chromium PC 1366×768,
모바일 390×844·375×667에서 입장, 키보드/터치 이동, 전 공정, 발원·걸기·점등,
새로고침 후 자신의 등 1개 유지가 통과했다. 페이지 오류·Supabase HTTP 호출·쓰기 시도는
모두 0건이었다. 방명록은 오프라인 안내만 검사했으며 운영 게시글 쓰기는 시험하지 않았다.
이미지와 결과는 로컬 `outputs/v6/`에 있다.
