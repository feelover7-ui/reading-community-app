# 도량 여백 조경 시안

사용자 승인: 돌길 + 가장자리 조경 + 동상 앞 작은 쉼터. 실제 도량의 조경 실측 복원이 아닌 게임용 배치다. 건물/연못을 추가하지 않는다.

- 작업장 출구→탑 북쪽 폭3.4, 동상→주동선 폭2, 탑 오른편→법당 폭2.6의 밝은 돌길.
- 기존 구정탑 원형 포장/탑돌이 반경4 유지.
- 외곽 낮은 화단4곳, 나무4그루. 중앙 남쪽 마당은 군중/이동 공간으로 비운다.
- 동상 남쪽 옆 쉼터 벤치2개. 앉기 기능은 없으며 참배 위치(8,35.6)를 막지 않는다.
- 길 옆 작은 방향 안내판. 사용자 입력/외부 이미지 없이 고정 문구.
- gardenLayout.js가 시각 모델과 충돌 사각형의 공통 기준. 화단/벤치/안내석 충돌 등록. 중앙/입구에 장식 장애물을 흩뿌리지 않는다.
- 관목/수관/줄기/벤치 상판/다리 총5개 인스턴스 배치. 고정 모델, 프레임별 갱신/새 조명/그림자 투사/외부 다운로드/새 라이브러리 없음.

## 검증
도구 V8에서 실제 campusScene의 solid 초기화 코드와 새 gardenLayout을 실행:
- 탑 반경4 원형 경로360표본 중 차단0.
- 법당 문(30.8,41), 동상 참배(8,35.6), 쉼터 접근(9,46): 캐릭터 네 모서리 보행 가능.
- 작업장 바깥(18,26)에서 법당/동상/쉼터/탑 옆까지 그리드 BFS 도달 PASS.
- 새 모듈 JavaScript 구문 검사 PASS.
- 브라우저/실기기 화면, FPS, 가림/밤 밝기, 80명 시야 시험 NOT RUN. Vercel 빌드는 별도 배포 상태로 확인한다.

## 실행 환경 인계
npm run build 후 모바일 세로/가로에서 작업장→동상→탑→법당 왕복, 벤치/화단 통과 방지, 자동 탑돌이3바퀴를 확인한다. 기존 tests/campus-v2.test.mjs와 tests/mobile-ui.test.mjs도 실행한다. 성능 수치를 측정하기 전 80명 무지연을 보장하지 않는다.


## 작업장 주소와 새 시안 기준 (사용자 정정)

- 2026-11-09 사용자가 등불사 작업장을 **경기도 안양시 만안구 석수동 93-1**로 지정했다. 용도 근거는 사용자 제공이며 웹 검색으로 확인된 것으로 표현하지 않는다.
- 기존 생성 이미지의 작은 야외 작업대는 사용자 의도와 다르다. 후속 시안은 작업장을 별도 건물·출입구가 있는 공간으로 표현한다.
- 브라우저 Chromium/카카오맵 스카이뷰로 본원 주변 항공사진을 실제 확인했다. 다만 93-1의 필지 경계/해당 건물/출입구/본원 연결 동선은 아직 지도에서 특정하지 못했다.
- 실제 본원과 다른 넓은 사각 마당 이미지를 위성사진 기반 재현이라고 쓰지 않는다. 기존 게임 좌표를 주소만으로 임의 이동하지 않는다.
- 다음 배치 시안 전에 카카오맵에서 '안양시 만안구 석수동 93-1'을 검색하고 스카이뷰/지적 경계와 본원을 함께 비교한다. 확인한 위치와 게임용 축약을 구분한다.
