# 동상 주변 잔디 복원

사용자가 동상 주변도 잔디라고 지적해 공식 one_tour_0801.jpg와 외부 전경 one_about_01.jpg를 다시 확인했다. 동상 아래 낮은 돌판 바깥과 화엄석 앞·옆은 잔디이고 보행로는 그 바깥으로 지난다. 이전 승인 조경안 중 동상 주변 포장은 이번 명시적 요청으로 수정한다.

기존 statue-back 식재면을 동상/참배 방향 기준으로 확장하고 잔디 재질을 지정했다. 중앙 큰 잔디·구정탑 포장·오른쪽 조경·나무/관목/바위 좌표는 그대로다. 참배 자리는 잔디 밖 포장에 남으며 보행 판정은 바꾸지 않았다. 렌더와 미니맵은 같은 조경 데이터를 쓴다. 동상 바깥의 튜브 고리 경계는 없애고 받침 아래 낮고 넓은 석판으로 바꿨다. 동상·화엄석·법당 등의 위치/방향은 유지했다.

검증: 테스트114개 통과(받침 양옆/화엄석 주변 잔디와 참배 자리 포장·보행 검증 추가), 빌드와 git diff --check 통과. 기존 Three.js 번들 크기 경고 유지. Chromium PC1200×900/모바일 모형390×844에서 전체 보기·동상 자동 정면·직접 클릭/터치 설명 확인, pageerror0.
