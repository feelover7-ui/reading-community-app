# v8 통합 배포 — 2026-11-15

기준 main 14edd92, PR35 병합 상태 확인. 사용자 요청은 남은 작업 일괄 구현·배포 후 외형 수정이다. 기존 배치·건물·탑·동상 위치와 v1/독서 화면은 변경하지 않는다.

## 변경

- 새 v6 얼굴과 가방 없는 전신을 v7 스킨 메시로 통합. 남성 블루 셔츠/짙은 바지, 여성 로즈 겉옷/밝은 바지. 기본 옷 색·피부·머리 색 저장을 반영한다. 머리 선택 UI는 구현된 모델 기본 머리로 정리했다.
- 관절 가중치로 팔·손목·어깨를 연결하고 걷기, 합장, 절, 등 운반 시 기존 동작 계약에 연결했다. 실제 runtime actor로 기본 초상을 다시 렌더했다.
- 각 캐릭터는 한 개의 skinned draw. 스켈레톤/개별 geometry 해제를 연결하고, 원격 캐릭터를 가까운 순 모바일12/PC24로 제한한다. 접속자 목록에는 전체를 유지한다. 이 수는 접속 수용량이 아니다.
- 지도 아이콘과 전체 조감도, 9개 장소 즉시 이동. 연결실은 실제 내부 복원이 아닌 이동용 공간이라고 표시한다.
- 완성→발원→걸기→점등→선택 참배. pendingHang 등은 공유·전시되지 않는다. 중복 제출 잠금, 저장 후 새로고침 복구와 구버전 미완료 등 이전을 추가했다.
- 상시 대화, 60개 스크롤 기록, 다른 장소 태그, 접기/새 글 표시, PC 입력칸/모바일 쓰기, 짧은 전송 속도 제한과 초안 보존. 방 이름 UI는 없고 설정에서 재접속/나가기. 이전 방 선택은 보존한다.

- Blender 생성과 Three.js 스킨 로딩/가중치·유한한 좌표·바닥 경계·개별 해제 검사.
- 실제 게임 renderer에서 남녀 전신/얼굴을 캡처하고 기본 초상을 생성. `outputs/reference-heads-v6/*-ingame-release.png`.
- PC 1440×960 지도 9개 터치 영역, 작업장/법당 즉시 이동, 완료 등 전시 지연, 발원 작성/걸기/공유 호출1회/점등 후 finale 확인. 저장 쓰기는 stub이며 운영 DB를 쓰지 않았다.
- 같은 출처의 두 탭 간 BroadcastChannel 메시지로 다른 장소 태그·문자 escape·접기 새글·15초 이후 기록 유지·Escape 초안 보존을 확인했다. 모바일390×844에서도 입력 표시와 하단 HUD 비겹침 확인. 서버 transport 회귀는 별도 자동 시험 범위다.
- 전체 시험/최종 모바일 흐름/배포 상태는 아래 최종 기록에 추가한다.

## 리뷰 및 판단

- 중요: 여러 창에서 등 걸기 중복 실행 → controller 단위 claimHang 잠금/진입 가드/행동 숨김, 회귀 시험 RED→GREEN.
- 중요: 구버전 tower/hall 체크포인트가 걸기를 건너뜀 → 미완료 등만 pendingHang으로 이전하고 걸이대부터 재개, 회귀 시험 RED→GREEN.
- 추가: 겉옷 색 커스터마이즈와 기존 저장 방 재접속을 보존했다.
- Ruling: 사용자가 배포 후 외형 수정을 선택했으므로 시안의 완전한 외형 일치 대신 새 모델 통합을 이번 출시 대상으로 했다. 얼굴/머리·손·절 자세의 시각적 완성도는 후속 다듬기 대상이다.
- Ruling: 최신 등걸이대 요청에 따라 제작→걸기→선택 참배로 변경했다. 이전 기록 이전이 함께 필요해 회귀 시험을 추가했다.
- 작은 잔여: 초상은 성별별 기본 모델 렌더다. 선택 색/상점 의상별 초상 실시간 갱신은 하지 않는다. UI에 기본 모습임을 안내한다.

## 검증 한계

실제 iPhone Safari 기기가 없다. 모바일 Chromium 화면 모형은 실기기 시험이 아니다. 소프트웨어 GPU의 속도는 실제 기기 성능이 아니다. 운영 DB에 새 방명록/공유 등 데이터를 쓰지 않았으므로 운영 쓰기 성공을 주장하지 않는다. 채팅은 세션 기록이며 영구 저장이 아니다. 기존 실제 사진 기반 공간은 근사 모델이다.
