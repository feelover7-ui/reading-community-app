# v8: 스페이스바로 입장 (2026-11-14)

사용자 요청: `스페이스바 누르면 입장되게 했으면 좋겠어`.

## 원래 있던 것

v8 에는 이미 **E 키**가 있었다. 가까운 곳이 있으면 `#interactBtn` 에 `입장 E` 라고 떴고,
`near` 판정도 매 프레임 돌고 있었다. 새로 만들 것은 없고 **키만 하나 더 받으면 됐다.**

## 고친 것 — 세 가지

`public/v8.html` 의 전역 `keydown` 한 군데다.

**1) Space 를 받는다.**

**2) 한글 입력 상태의 E.** 원래 `e.key.toLowerCase()==='e'` 뿐이었다.
한글 입력 상태에서는 `e.key` 가 `'ㄷ'` 으로 와서 **E 가 안 먹었다.** 이제 `e.code==='KeyE'`
를 먼저 본다. 이 저장소의 다른 화면들이 이미 같은 이유로 `e.code` 를 쓴다
(`바깥 화면 공용 엔진` 절). v8 만 빠져 있었다.

**3) 단추에 초점이 있으면 Space 를 넘긴다.**
Space 는 초점이 있는 단추를 누르는 키이기도 하다. 안 가리면 **한 번 눌러 단추도 눌리고
입장도 된다.** `BUTTON·A·SUMMARY·DETAILS` 에 초점이 있으면 입장시키지 않는다.
이것도 이 저장소에 이미 있던 교훈이다(`게임 화면의 버튼은 releaseFocus()` 절).

단추 글자는 `입장 Space·E` 로 바꿨다. 세 화면의 `살펴보기(Space·E)` 와 같은 표기다.

## 확인한 것

이 컨테이너의 3D 는 소프트웨어 렌더라 3fps 여서 **걸어서는 문 앞까지 못 간다**(기존에
적어 둔 한계). v8 에는 `__warp` 가 없다. 대신 **WebGL 을 막아 2D 대체 렌더러로 돌려**
걸어갔다. 내가 고친 전역 `keydown` 은 두 렌더러가 같이 쓴다.

```
시작             : near=false · 버튼 "작업 Space·E"      · 방 한마음선원 도량
문 앞            : near=true  · 버튼 "입장 Space · E"    · 방 한마음선원 도량
Space            : → 방 무진향 · 버튼 "나가기 Space · E"   ← 입장됨
단추 초점 + Space : 방 한마음선원 도량 그대로 · 도움말 창만 열림  ← 겹치지 않음
초점 풀고 Space   : → 방 무진향                            ← 다시 입장됨
```

`tests/v8-lanterns.test.mjs` 에 세 가지(Space·`e.code`·초점 가림)를 구조로 지키는 시험을 넣었다.

## 남은 것

- **3D 렌더러에서 걸어가 Space 를 누르는 것은 이 환경에서 확인하지 못했다.** 키 처리는
  2D·3D 가 같은 코드지만, 3D 에서 문 앞까지 걸어가는 것 자체를 못 해 봤다. 실기기에서 본다.
- 조이스틱으로 걸어가 Space 를 누르는 흐름(휴대폰)은 확인하지 않았다. 휴대폰에는 자판이 없고
  `작업` 단추가 따로 있다.
