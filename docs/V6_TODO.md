# v6 보류 작업

- [ ] 실명 확인 및 회원 승인: 현재는 이름을 직접 입력하는 방식. 실명 검증·인증된 출석 없음.
  이전 선택은 회원 명부 대조와 관리자 승인 방식이며 사용자가 구현을 보류했다.
  관리자 계정, 명부 관리 위치, 확인 기준은 정해지지 않았다.
  후보: 선원 회원명부 대조/관리자 승인, PASS·NICE·KCB 등의 휴대폰 본인확인.
  일반 카카오·네이버 프로필 이름만으로는 본인확인으로 처리하지 않는다.
  구현 시 서버 인증/권한과 표시 이름을 분리하고 이름 변경을 클라이언트만으로 허용하지 않는다.
  접속 안내와 검증된 출석 저장은 별도 기능으로 구분한다.
