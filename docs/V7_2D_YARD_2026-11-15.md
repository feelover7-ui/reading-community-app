# v7 — 2D 등불사장만 (2026-11-15)

사용자 요청: **"예전 2D 버전으로 돌아가자 v7.html로 만들어줘. 불사장만 있는 버전으로."**

기준 main `fbe8da5`. 폴더별 설명은 `v7/ORIGIN.md`.

## 어떤 2D 인가

등불사장은 처음에 2D 캔버스였고 커밋 `95930ab`(*세 화면을 모두 3D로 바꾸기*)에서 three.js
로 바뀌었습니다. v7 은 **그 직전 `d886cfa` 의 코드**입니다. 도트 캐릭터
(`pixelCharacter.js`, 24×36)로 그리고 three 를 전혀 가져오지 않습니다.

`/original.html`(사용자가 처음 보낸 3D 원본)과 혼동하지 않습니다.

## 옮긴 것

`v7.html` + `v7/` 여덟 파일. 공용 엔진 `sceneKit.js` 는 통째로 베끼지 않고
실제로 쓰던 `releaseFocus` 하나만 `v7/focus.js` 로 옮겼습니다.

네 파일(`lanternsApi`·`boardApi`·`pixelCharacter`·`supabaseClient`)은 **한 글자도 안 고쳤고**
`v7/tests/standalone.test.mjs` 가 SHA-256 으로 지킵니다.

## 고친 것 셋

1. **저장소 키 5 개에 `v7-`** — 같은 출처라 안 붙이면 `/deungbul.html`·`/v8.html` 진행을 덮습니다.
2. **접속 채널 `v7-deungbul-yard`** — v7 은 36×26 칸이고 운영 맵은 126×70 입니다.
3. **나가는 문 제거** — *불사장만* 이라는 요청입니다. 위쪽 벽 구멍을 메우고, 문 물체·
   살펴볼 곳 항목·`travelTo`·`?from=doryang` 을 지웠습니다. `drawGate()` 는 나중을 위해 남겼습니다.

## 모바일 점검과 고친 것 (2026-11-15 후속)

배포본 `/v7.html` 을 네 크기로 열어 실제로 눌러 봤습니다.
iPhone SE 375×667 · iPhone 13 390×844 · Galaxy S20 360×800 · 가로 844×390.

### 잘 되던 것

- 가장 좁은 375×667 에서도 `마당에 들어가기` 단추가 화면 안에 들어옵니다(52px).
- **조이스틱을 실제로 끌어 걸어집니다.** 손잡이도 손을 떼면 제자리로 돌아옵니다.
- 터치 크기 — 조이스틱 132 · 작업 86 · 마당 메뉴 44.
- 마당 메뉴 창이 네 크기 모두 화면 안에 들어오고 안쪽이 스크롤됩니다.
- Supabase **쓰기 요청 0건**, 콘솔 오류 0.
- 휴대폰 조작 안내는 `game.js` 가 조이스틱 기준으로 바꿔 줍니다.

### 고친 것 셋

**① `펼치기` 를 누르면 대화창이 열렸습니다.**
`#topbtns`(💬 🔊 🎵 ?)가 소임 상자 오른쪽 위를 덮고 있었습니다.
390×844 에서 상자 x 12\~224, 단추 줄 x 178\~378 — 46px 이 겹치고
`펼치기` 가 꼭 그 안에 있었습니다. `elementFromPoint` 로 재 보니
그 자리의 실제 요소가 **`chatb`** 였습니다.
좁거나 낮은 화면에서 상자를 단추 줄 아래(`top +52px`)로 내렸습니다.

> 상자 머리 전체(`#hudh`)가 토글이라 왼쪽 글자를 누르면 펼쳐지기는 했습니다.
> 그래도 보이는 단추를 누르면 엉뚱한 창이 열리는 것은 고쳐야 할 일입니다.

**② 눕힌 화면에서 소임 상자가 조이스틱까지 내려왔습니다.**
844×390 에서 상자가 272×366 — 화면 높이의 94%, 면적의 30% 였습니다.
접는 판정이 가로폭만 보고 있어서(`vw<640`) 눕히면 안 접혔습니다.
`vw<640||vh<520` 으로 고치고, 낮은 화면의 `max-height` 를
`calc(100dvh - 230px)` 로 막아 조이스틱 위에서 멈추게 했습니다.
(z-index 는 조이스틱 6 · 상자 5 라 조이스틱 자체는 눌리고 있었습니다.)

**③ 없어진 문을 가리키던 조작 안내.**
`v7.html` 의 `#ctlhint` 가 `위쪽 문으로 나가면 본원 도량` 이라고 적고 있었습니다.
휴대폰에서는 `game.js` 가 덮어써서 **PC 에서만 보이던 글**입니다.
