# sansatemple.com 분석 (2026-11-14)

사용자가 기준으로 가리킨 사이트입니다. 직접 열어 보고 적었습니다.
**화면 캡처와 에셋은 저장소에 넣지 않습니다.** 읽은 내용과 숫자만 남깁니다.

## 1. 무엇인가 — v8 과 같은 장르입니다

- 제목 `산사, 잠깐 쉬어가요` · 주소가 `?room=maru-02&instance=0&region=apac`
- WebGL 캔버스 한 장. `THREE` 전역이 없으니 번들된 엔진입니다(Vite `assets/index-*.js` 한 덩어리).
  외부 스크립트는 Google Analytics 와 Cloudflare Insights 둘뿐입니다.
- 할 수 있는 것: **합장 · 절하기 · 목탁 · 염주**, 방 고르기(`산사 02`·`03`), 지도, 염불 듣기,
  날씨·소리·설정.
- 조작: `바닥 클릭 · 드래그로 둘러보기 · 휠로 확대/축소`
- 다른 사람이 같은 마당에 여럿 보입니다.

**기능은 v8 과 거의 같습니다.** 다른 것은 만듦새입니다.

## 2. 캐릭터 — 제가 계속 빗나간 이유

| 저쪽 | 제 시안들 |
| --- | --- |
| **민머리 동자승** | 매번 바가지 머리를 얹었습니다 |
| **목이 없음.** 머리가 어깨에 바로 얹힘 | 1차에서 목을 만들었습니다 |
| **큰 색면 두 개**(회청 승복 + 겨자 가사) | 청록 옷에 흰 리본 **한 줄** |
| **얼굴이 거의 안 보임**(늘 뒤에서 봄) | 눈·코·입·눈썹·볼을 다듬고 있었습니다 |
| 약 **3.4등신**, 통통, 모서리가 전부 둥금 | 2.2 → 3 등신으로 고치는 데 집중 |

가장 큰 하나는 **머리카락**입니다. 바가지 머리 하나 때문에 무엇을 바꿔도 "인형"으로 보였습니다.

## 3. 화면

- **해질녘 한 가지 시간대.** 남보라 하늘(`#1c3c55`) → 지평선 갈색(`#392e2a`)
- 먼 산은 안개로 흐리게. 단풍 붉은 잎과 흩날리는 잎
- 바닥은 회색 판석(`#464646`), 마른 들(`#523827`), 올리브 잔디(`#52482e`)
- **법당 문 안쪽 금빛만 밝습니다.** 화면에서 제일 밝은 점이 거기 하나입니다
- 쓰는 색이 적습니다. 갈색·회색·남색에 겨자 하나.

## 4. UI

- 좌상단: 뒤로 / 지도 / `산사 02 ▾`
- 우상단: 날씨 구슬 / 음소거 / 설정
- **하단 가운데 알약 띠에 아이콘 넷**(합장·절하기·목탁·염주). 그게 전부입니다
- 머리 위 이름표: 크림색 알약 + 올리브 원형 배지 `나` + 이름
- 상단 가운데 한 줄 안내

**메뉴가 없습니다.** 할 일이 네 개뿐이고 네 개가 다 보입니다.
v8 은 장면 아홉에 활동이 여럿이라 메뉴가 생겼고, 그만큼 화면이 복잡합니다.

## 5. 베끼지 않습니다

같은 장르·같은 복식이라 수렴하는 부분이 있습니다. 다만 모델·코드·에셋은 직접 만듭니다.
저쪽 화면이나 파일을 저장소에 넣지 않습니다. 이 문서도 관찰만 적은 것입니다.
