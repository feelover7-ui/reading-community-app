# v8 모바일 제작 화면과 과정 검토

## 재현한 문제

390×844 화면에서 제작 미리보기는 높이256px, 골조 작업판은 y572~834에 있었다. 모달 본문은 y766에서 끝나므로 작업판 아래가 잘렸다. 본문 전체 높이는910px로 가용645.5px를 넘었다. 미리보기의 sticky 배치, 위아래로 쌓인 큰 여백, 공정 전환의 scrollIntoView가 겹쳤다. 매 조작마다 전체 작업 DOM을 다시 만들며 기존 스크롤·키보드 초점도 보존하지 않았다.

## 변경

- 제작 모달만 모바일 화면 높이에 맞춘다. 진행 중에는 등 미리보기를 작은 가로 카드로 두고 작업판·안내·하단 다음 버튼을 함께 보여준다.
- 짧은 세로 화면에서는 다시 시작 버튼을 상단으로 옮긴다. 가로 화면은 왼쪽 미리보기, 오른쪽 작업판/조작으로 나눈다. 전기·매듭·한지·색 버튼은 최소44px의 터치 영역을 유지한다.
- 작업 도중 스크롤과 키보드 초점을 보존하고 공정 변경 시 본문만 처음으로 돌린다. scrollIntoView로 미리보기를 밀어내지 않는다.
- 등 캔버스는 실제 표시 크기에 맞춰 그린다. CSS만 줄여 등이 찌그러지지 않게 한다.
- 기본 공정은 골조→전기→한지→채색이다. 한지는 03·1 실 바탕/03·2 조각 붙이기로 구분한다. 미리보기에서 매듭 진행도도 보여준다.
- 고요한 참배 UI에서는 남아 있던 점수·감점 문구를 정리한다. 저장된 점수, 보상 계산, 진행 저장 형식과 완료 판정은 보존한다.
- 완성 시 '완성한 등 확인하기'→'완성한 등 들고 나가기'로 안내한다. 실제 등걸이대에서 이름과 발원을 적고 걸기 전에는 전시 완료로 안내하지 않는다.

## 제작 과정 평가

| 작업 | 검토와 반영 |
| --- | --- |
| 골조 | 점선 양끝을 눌러 연결한다. 잘못 누른 뒤에도 작업판이 움직이지 않고 재시도할 수 있다. |
| 전기 | 회전 타일 9칸을 모두 이어야 한다는 조건을 처음 안내에 명시한다. 점등 확인은 별도 버튼으로 유지한다. |
| 한지 바탕 | 실 선택→같은 표식의 고리→매듭 순서다. 실 작업이 한지 공정의 일부임을 명시한다. |
| 한지 붙이기 | 조각과 밑그림을 동시에 보고 탭 두 번으로 놓는다. 기존 끌어놓기 경로도 보존한다. |
| 채색 | 번호 색을 선택해 해당 부분을 칠한다. 색상만으로 정답을 구분하지 않는다. |
| 완료 | 완성품을 가져간 뒤 등걸이대에서 발원·걸기로 이어진다. pendingHang 상태를 유지한다. |

공정은 현재 연결/맞추기 퍼즐 방식이다. 손이 재료를 실제로 조립하는 애니메이션까지 구현한 것은 아니다. 선택한 등 모양과 모든 작업 도안이 일치하도록 다시 만드는 것은 별도 시각 작업으로 남는다. 이번 변경은 조작 중 시야 유지와 과정 이해를 다룬다.

## 검증 기준

`scripts/qa-v8-mobile-craft.cjs`는 실제 앱에서 좌표 기반 터치/클릭으로 전 공정을 마친다. 자동 스크롤이나 강제 클릭 없이 미리보기·작업판·조작 영역이 본문 안에 있는지, 본문 overflow와 scrollTop이0인지 확인한다. 잘못 연결한 경우, 완성된 공정, 중간에 닫고 다시 연 한지 진행, 완성품의 pendingHang도 검증한다. REST 쓰기는 차단한다.

실제 iPhone Safari/GPU와 운영 DB 쓰기는 이 자동 Chromium 검증과 별개다. 화면 확대와 입력 키보드 등으로 공간이 부족해지면 접근성을 위해 수동 스크롤을 허용한다. 선택 화면과 발원 입력을 무조건 잘라내지 않는다.

최종 로컬 확인: Chromium 390×844, 375×667, 375×560, 844×390, PC1280×900 모두 제작 완료·pendingHang 유지·pageerror0. 각 공정에서 본문 overflow0과 scrollTop0을 확인했다. 375×667/375×560/844×390/1280×900은 한지 두 조각을 붙인 뒤 닫기/재개도 통과했다. PC는 모달 높이를 고정해 조작 결과에 따라 창 전체가 다시 가운데로 움직이지 않게 했다. `node --test tests/*.test.mjs` 356/356, 빌드와 diff 검사 통과(기존 Three.js 번들 크기 경고 유지).
