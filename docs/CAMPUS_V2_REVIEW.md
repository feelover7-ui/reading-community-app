# 원본 외부 맵·구정탑 탑돌이·법당 시점·relay v2

사용자 요청: 앞선 점검 문제를 반영하고 맵을 처음 공유한 것으로 바꾸되 법당 내부는 기존 것을 사용. 추가로 구정탑 중심 탑돌이와 법당 내부 시점을 검토/개선.
기준 main: 54ad73da021dd8d8bd916a6bea472c5f9546a2a8. 독서 홈페이지는 변경하지 않음.

## 화면/동선

- deungbul.html은 원본 HTML에서 파생한 campusScene.js를 사용. 작업장·등 마당·본원 외부의 원래 구도/건물/캐릭터/미니맵을 복원한다.
- 최신 '처음 맵으로 교체' 요청에 따라 원본에 있는 건물과 배치를 사용한다. 이전 건물 삭제/작업장 뒤쪽 오른편 요청을 우선 적용해 원본 구도를 다시 바꾸지는 않는다.
- 원본 내부 법당 모델은 운영 장면에서 제거. 외부 법당 입구에서 안내→입장으로 기존 beopdang.html에 연결한다. 출구는 원본 법당 앞(33,50.4). 기존 도량 URL도 새 외부 맵에 연결한다.
- 기존 법당 건축·불단·좌복·절 기능은 유지. 카메라는 캐릭터와 불단을 함께 담는 가로/세로 FOV 기반 기본 시점을 제공한다. 끌기/Q/R/휠은 자유 시점, 🧭는 기본 시점 복귀. 기존 벽/천장 걷어내기는 유지한다.
- 구정탑 모델·안내 원·회전 계산은 PAGODA_CENTER(22,41)를 공유. 안내 걷기/직접 걷기, 시계방향 세 바퀴, 중단, 완료. 역방향은 진행을 되돌리고 중심 통과/순간 이동은 회전으로 세지 않는다.
- 원본 preview는 그대로 보존. 새 상태는 hanmaum-campus-v2에만 저장하고 이전 hanmaum-deungbul-v1을 읽기만 한다. 기존 앱/preview 저장 키를 덮지 않는다.
- 기존 lanterns/board API로 공동 등불·방명록·대화·소원 목록을 연결. 원본 걸이줄 수보다 많은 등은 목록에서 확인한다. 오프라인 등은 자동 업로드하지 않고 쓰기 결과 불명확 시 자동 재전송하지 않는다.
- 모바일 DPR 1.25/그림자 끄기, 숨김·시작 전 렌더 중지, 사용하지 않는 등 텍스처 정리, 관절 인형 교체 시 GPU 자원 정리. 원본의 장식 전체에 동작 줄이기가 완전히 적용됐다고 주장하지 않는다.

## 통신 수정

- presence.js의 실제 joinYard 경로가 relay 설정을 읽는다. 원본 외부와 기존 법당 둘 다 사용한다. 설정이 없으면 기존 Supabase 경로이며 두 경로를 동시에 켜지 않는다.
- client 입력 4KiB와 server 명단 128KiB 분리. 80인 welcome을 작은 입력 제한으로 버리는 문제 수정.
- full snapshot은 명단을 교체, 서버 seq gate 적용, 재동기화는 hello/전체 상태 요청으로 처리. 정지 상태 heartbeat로도 유실된 delta를 복구.
- DO 참가자·유예·epoch·seq를 storage에 저장, blockConcurrencyWhile로 복원. 기존 socket id를 기존 참가자와 연결해 복귀한다.
- 재접속 토큰은 crypto.randomUUID. 반복 hello는 참가자를 늘리지 않고 입력 속도/hello 미완료/방 이름/장면/행사 event를 제한.
- 부하 도구는 현재 명단과 removed/full을 반영하고 회전값을 정규화한다. 실패 시 exit 1, 전용 load-test 방만 허용, 실제 bytes와 서버 상태 age를 별도 보고한다.
- Origin은 인증이 아니며 초대 인증은 여전히 미구현. 임의 위치 이동은 경계/속도 필드까지만 검사한다. 실제 이동거리/충돌의 서버 권한 검증은 남아 있다.

## 이 환경에서 확인한 것

Node/셸/workerd와 브라우저 렌더 실행 환경이 없다. V8 도구에서 모듈의 import/export를 제거하고 의존 API를 주입해 같은 함수/테스트 본문을 실행했다. TextEncoder 대신 UTF-8 byteLength shim, crypto/WS/storage는 테스트 대역을 사용했다. 이는 npm test 또는 실제 Cloudflare/기기 검증과 다르다.

- 기존 프로토콜/방 로직 16개 + 신규 relay/DO 복원 회귀 5개 = 21개 PASS.
- 신규 탑돌이/카메라 계산 4개 PASS. 시계 방향 세 바퀴, 앞뒤 왕복/역방향, 중심/순간 이동, 세 해상도와 네 위치에서 주요 대상 시야 계산을 검사.
- 구정탑 반경4 안내 원의 360개 위치에서 몸체 네 모서리와 원본 solid 배열 대조: 막힌 표본 0. 실시간 NPC와 사용자 이동은 별도.
- 변경 JavaScript 구문 검사. 실제 번들 검증은 Vercel preview 결과를 별도 기록한다.
