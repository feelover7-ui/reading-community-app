## 이번에 확인할 동작

1. 작업장/등 만들기는 원본 맵을 유지하고 작업장 밖 건물은 법당 한 동만 탑 오른편에 배치.
2. 외부 법당 입구/복귀/충돌/미니맵/가이드가 같은 위치를 사용. 법당 내부는 기존 모델/좌복/절 기능 유지.
3. 자동 탑돌이 시작 버튼으로 직접 조작 없이 세 바퀴 완주. 중단/방향 입력/막힌 길/화면 복귀 처리 확인.
4. 법당 자동 구도에 캐릭터와 불단이 들어오고, Q/R·끌기·휠은 자유 시점, 🧭는 자동 구도로 복귀.
5. 구정탑9구/동상의 연화좌대·화엄석7개·물결 경계석 시안과 공식 사진을 실제 화면으로 비교. 현재 사진 픽셀 직접 대조는 미실행.
6. 기존 공유 소원등·방명록·대화·개인 기록과 접근성/WebGL 재시도 유지.
7. 80명 relay의 큰 명단 수신·재접속·DO 상태 복원·seq·주소 허용 목록 확인.
