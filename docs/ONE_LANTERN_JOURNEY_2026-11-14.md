# v8 첫 등불 여정 구현·검증 기록

## 구현 결과

- 첫 화면을 하나의 입장 행동과 현대 청년 남·녀 모습 선택으로 단순화했다.
- 기존 골조·전기·한지·채색 제작을 그대로 사용하고, 새로 완성된 등 하나만 골라 캐릭터가 든다.
- 구정탑 12개 지점을 시계방향으로 자동 한 바퀴 돈 뒤 5층 법당의 기존 자연스러운 삼배로 이어진다.
- 마지막에 이름을 정해 등을 걸고, 도량 전체 야간 피날레 뒤 자유 탐방으로 전환한다.
- 재방문 화면은 전체 장소·장소별 접속자·방명록·설정과 기록을 중심으로 줄였다.
- 공유 등은 작성 시각과 밝힌 사람 수를 표시하고 다른 사람의 등만 한 번 밝힐 수 있다.
- 방명록은 날짜와 시각을 함께 표시하며, 백엔드가 없을 때는 로컬 저장 상태를 명시한다.

## 검증

- 루트 전체 Node 테스트: 309 통과, 실패 0.
- Durable Object relay worker 테스트: 43 통과, 실패 0.
- Vite 프로덕션 빌드와 `git diff --check`: 통과.
- Chromium CDP 1440×900 및 390×844: 첫 화면과 44px 이상 주요 조작 확인.
- 실제 브라우저 흐름: 익명 입장, 제작 완료 이벤트, 자동 탑돌이, 법당 삼배, 이름 입력,
  피날레, 재방문 HUD, 장소별 접속자, 방명록 로컬 폴백 확인.

## 정확한 제한

- 390×844 검증은 Chromium의 모바일 viewport 에뮬레이션이다. 실제 iPhone Safari 기기 성능과
  WebGL 안정성을 물리 기기에서 확인했다고 주장하지 않는다.
- `public.blessing` 또는 `public.posts` 표가 운영 Supabase에 없거나 RLS 정책이 적용되지 않았으면
  각각 점등과 방명록은 로컬 전용으로 동작한다. 앱은 이 상태를 화면에 표시하며 여정을 막지 않는다.
- Three.js 번들은 기존과 같이 500 kB 경고가 남지만 빌드는 성공한다.
