## 세 지점90도 회전·본관 긴 직사각형 보완 (최신)

- 사용자 요청: 칠보탑/구정탑/동상 전체90도 회전, 본관은 위성사진으로 확인해 긴 직사각형으로.
- 임시 Chromium 카카오맵 스카이뷰에서 본원 주소를 다시 검색·확대하여 실제 항공사진 픽셀을 직접 대조했다. 본관의 긴 장축과 여러 지붕 면/연결부가 확인된다. 단순 정사각형처럼 만든 이전 모델을 수정한다. 지도 이미지를 배포 자산에 복제하지 않는다.
- 회전 방향이 지정되지 않아 위에서 본 시계 방향90도로 적용하고 작업 시작 시 알렸다. 중심은 MAIN(24,42). 변환은 (dx,dz)→(-dz,dx)로, 세 점의 거리/삼각형 면적을 보존한다.
- 평면 기준 새 꼭짓점: 칠보탑(21.5,39), 구정탑(39,40), 동상(38,27). 칠보탑의 y는 바뀐 지붕 표면에 맞추며 지붕 위를 유지한다. 동상 정면은 새 좌표에서 법당으로 다시 계산한다.
