확인일: 2026-11-09. PR #20 후속 요청을 같은 브랜치에 반영한다. 기준은 #20 코드 5d0c451e68704d051b55e96e37023e2a89ec783b다.

## 사용자 요청 반영

- 작업장 밖의 원당/별관/자료관/요사채/심주관/어린이법당은 모델과 충돌에서 제거한다. 어린이법당 구덩이도 없애 평지로 연결한다.
- 법당 한 동만 구정탑 오른편에 배치한다. 캠퍼스 좌표 x=32,z=34,w=14,d=13, 서편 입구/법당 복귀는 (30.8,41)다.
- 가이드·미니맵·핀·입장 안내·복귀 위치를 함께 옮긴다. 법당 내부와 기존 카메라/절 기능은 변경하지 않는다.
- 탑돌이는 안내/직접 걷기 선택 대신 '자동 탑돌이 시작'을 기본으로 한다. 시작 뒤 직접 조작 없이 세 바퀴를 걷는다. 멈추기/방향 입력/장애물로 중단한다.
- 탑은 기존 (22,41), 동상은 기존 (8,32)다. 위치는 사용자 지정 게임 배치이며 실제 본원 지도라고 표현하지 않는다.

## 사진 확인의 한계

공식 페이지와 사진 URL은 웹 도구로 열었다. 그러나 사진 응답이 실제 픽셀 대신 ImageDisplayed placeholder와 URL만 반환돼 이 환경에서 눈으로 확대·대조하지 못했다.
위 조형 변경은 공식 설명에서 확인되는 구조를 기준으로 한다. 사진을 실제로 보고 검수한 실물 재현 완료가 아니다.
후속 실행 환경에서 위 사진과 preview를 나란히 띄워 구의 비율, 받침, 동상 자세, 화엄석 배치를 검토해야 한다.
공식 사진을 저장소에 내려받거나 모델 텍스처로 넣지 않았으며 게임 도움말과 탑돌이 안내에는 공식 페이지로 가는 링크를 제공한다.

## 검증

- 구정탑 반경4 안내 원 360개 표본: 충돌 지점0.
- 새 법당 입구/복귀, 동상 앞 삼배 위치, 탑돌이 시작점: 캐릭터 네 모서리 기준 보행 가능.
- 작업장 바깥 입구에서 위 지점까지 실제 solid 그리드 BFS로 도달 가능.
- 실제 solid 충돌 함수를 사용해 .05초 단위 자동 탑돌이를 541단계 진행: 조작 없이 세 바퀴 완료, 장애물 중단0.
- 변경 JavaScript 문법 검사 수행. Vercel preview 빌드는 별도 확인.
- 실제 3D 화면/모바일 조작/사진 픽셀 대조/80명 연결은 이 환경에서 미실행. 추가 모델은 정적이며 새 이미지 요청이나 외부 3D 파일 다운로드를 추가하지 않는다.
