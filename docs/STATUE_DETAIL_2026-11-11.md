# 대행선사 동상 세부 표현

사용자 요청에 따라 공식 정면 사진 https://hanmaum.org/content/one_tour_08 의 one_tour_0801.jpg를 참고했다. 둥근 안경, 볼·턱·귀·콧방울·눈꺼풀, 지팡이를 감싼 손가락, 겹친 깃·법의 주름·가사 격자와 연결 무늬, 열린 고리 형태의 지팡이 머리를 기하로 보강했다. 법의 아래쪽 폭을 조금 넓혔으며 전체 시설 외곽/최고 높이는 기존 범위 안이다. 사진의 정밀 스캔이나 초상 복원이 아닌 경량 모델 개선이다.

동상 중심·그룹 배율·방향, 주변 화엄석 7개, 참배 자리, 길·잔디·건물 좌표와 기존 카메라/클릭 설명 코드는 유지한다. 원본 사진 텍스처·새 조명·런타임 의존성은 추가하지 않았다. 세부 장식은 두 재질로 병합해 추가 draw call을 2개로 제한했다. 전체 동상 약20,996삼각형이며 가벼운 화질에서도 얼굴과 손·옷 표현을 유지한다.

독립 코드 검토에서 지팡이 접합 틈과 법의 내부에 묻힌 장식을 발견해 수정했다. 지팡이 머리를 기울어진 줄기의 끝과 연결하고, 가사의 표면 깊이를 법의 반지름으로 계산했다. 재검토에서 중요 결함 없음.

검증:
- node --test tests/*.test.mjs: 기존113개 통과.
- npm run build, git diff --check 통과. 기존 Three.js 번들 크기 경고는 유지.
- 노드에서 모델 생성 후 모든 위치 속성의 유한값, 전체 bounds와 세부 병합2개 확인.
- Chromium PC1200×900 / 모바일 모형390×844: 전체 보기, 동상 정면 자동 시점, 실제 모델 클릭/터치 설명 열기·닫기, pageerror0 확인.
