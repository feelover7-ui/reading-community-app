# v8 발원등 공유 (2026-11-14)

## 왜

v8 은 **사람만 공유하고 등은 공유하지 않았다.** 두 사람이 같은 마당에 서서 서로 걸어다니는 건
보이는데, 전시장을 열면 **각자 자기 등만** 보였다. 등은 `localStorage` 에만 있었다.

`src/v8/realtime.js` 가 주고받는 것은 `presence`·`chat`·`gesture` 셋뿐이고 등은 0건이었다.
지난 며칠 붙인 relay 는 **위치를 나르는 길**이지 남아야 하는 기록을 두는 곳이 아니다.

## 기존 public.lanterns 를 쓰지 않는 이유

| | public.lanterns (등불사장) | v8 |
|---|---|---|
| 발원 길이 | **24자** | **180자** |
| 등 모양 | lotus·wheel·fish·elephant **넷** | lotus·round·star·wind·windbell·fish·elephant·wheel·square·palace·cloud·bell·lantern **열셋** |
| 등 이름 | 없음 | 40자 |

깎아 넣으면 발원문이 잘리고, 등불사장 화면에 **그릴 수 없는 모양**이 섞인다.
그래서 `public.v8_lantern` 을 따로 둔다. 두 앱이 서로 건드리지 않는다.

## 무엇을 했나

- `supabase/v8_lanterns.sql` — v8 전용 표. 기존 표들과 같은 임시 공개 MVP 정책(읽기 공개,
  넣기 공개, 수정·삭제 없음). 정책이 v8 의 열세 모양과 발원 2~180자를 그대로 받는다.
- `src/v8/lanterns.js` — 올리기·불러오기·실시간. **`select *` 를 쓰지 않고 컬럼을 적는다.**
  보내기 전에 서버 정책과 같은 기준으로 잘라 통째로 거절당하지 않게 한다.
- `src/v8/network.js` 가 `createLanternClient` 를 내보낸다. **통신(relay)과 별개다.**
- `public/v8.html` — 네 군데만 고쳤다.
  - 등을 다 만들면 `shareNewLantern()` 이 올린다. **실패해도 등은 이 브라우저에 그대로 남는다.**
  - 전시장이 `galleryRows()` 로 내 등과 남의 등을 시간순으로 합쳐 건다.
  - 머릿말에 `내가 밝힌 등 N개 · 함께 걸린 등 M개`.
  - 남의 등은 `shared-slot` 으로 표시하고 상세에 `다른 법우가 건 등입니다`.
- **`store.data.lanterns` 는 건드리지 않는다.** 그건 내 저장 파일이고 진행 기록(records.crafts)이
  거기 걸려 있다. 남의 등을 섞으면 내 기록이 틀어진다. 표시할 때만 합친다.

## 걸린 것

- **표가 없을 때 PostgREST 는 `PGRST205` 를 준다.** `42P01` 만 보고 있어서 못 알아봤다.
  둘 다 본다(`missingTable`).
- 첫 조회가 실패하면 클라이언트를 버려서 **영영 다시 시도하지 않았다.** 이제 버리지 않는다.
  SQL 을 돌린 뒤 전시장을 다시 열면 그때 붙는다. 새로고침도 필요 없다.

## 확인한 것

- 저장소 시험 232개 통과(`tests/v8-lanterns.test.mjs` 8개 포함), `npm run build` 통과.
- 실제 브라우저에서 전시장을 열었다. **표가 없는 지금도 안 깨지고** 로컬 모드로 떨어지며
  `지금은 이 브라우저에만 저장됩니다` 라고 정확히 알린다. 페이지 오류 0.
- 브라우저에서 모듈을 직접 불러 확인한 유일한 실패 원인:
  `Could not find the table 'public.v8_lantern'` (PGRST205). 그 밖은 정상이다.

## 아직 안 한 것

- **`supabase/v8_lanterns.sql` 을 아직 돌리지 않았다.** 그전까지 등은 이 브라우저에만 남는다.
  이를 공유 기록으로 표현하지 않는다.
- **올리기(쓰기)를 실제로 해 보지 않았다.** 로컬에서 운영 DB 에 쓰지 않는 규칙 때문이다.
  표를 만든 뒤 배포본에서 확인한다.
- 심지·밝혀 주기는 v8 에 아직 없다. 등이 공유된 다음 일이다.
