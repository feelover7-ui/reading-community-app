# v8 대화 입력·지도 키보드 조작

- PC: Enter로 입력을 열고, 글이 있으면 Enter로 전송한 뒤 입력을 닫는다. 빈 입력 Enter·Esc·닫기는 글을 보내지 않고 닫는다. 최근 60개 대화는 접속 중 유지한다.
- 모바일: 대화 버튼으로 입력을 열고 전송 성공 시 키보드와 입력창을 닫는다. 닫힌 상태에서는 최근 세 메시지만 표시하며 터치를 가로채지 않는다. 전체 기록은 입력창을 열어 읽는다. 입력 중 하단 빠른 메뉴/활동 안내를 잠시 숨기고, 초점이 버튼으로 옮겨져도 창 위치를 유지해 보내기·닫기 터치가 가려지지 않게 한다.
- 한글 조합 확정은 전송으로 처리하지 않는다. 중복 전송을 막고 실패 초안, 새로 고친 초안, 닫았다 다시 연 입력을 늦은 응답으로 지우지 않는다.
- PC: M → 현재 장소 선택 → 방향키로 지도상의 다음 장소 선택 → Enter 즉시 이동. Esc로 닫는다. 글 입력과 다른 대화상자에서는 M이 지도를 열지 않는다.
- PC 왼쪽 위 중복 지도 버튼을 숨기고 오른쪽 지도 아이콘을 유지한다. 기존 장소 배치와 아홉 목적지는 바꾸지 않는다.
- 첫 입장 안내를 DOM에서만 숨겨 내부 modal 상태가 onboarding에 남던 문제를 수정했다. 이 상태는 Enter/M을 차단했다.

## 검증

- Node 테스트 364개 통과. 입력 성공/실패/늦은 응답/한글 조합과 지도 방향 선택 회귀를 포함한다.
- `npm run build`, `git diff --check` 통과. 기존 500kB 번들 경고는 남아 있다.
- `scripts/qa-v8-enter-chat.cjs`: PC 1280×900, 모바일 390×844 Chromium. 실제 키 입력, 로컬 BroadcastChannel 수신, 실패 초안, 입력 중 이동 방지, PC 지도 아홉 장소 선택과 등불사장 즉시 이동을 검증한다.
- 브라우저 검증은 온라인 연결을 끄고 WebSocket·DB 쓰기를 차단한다. 운영 대화방에 테스트 글을 보내지 않는다. 실제 iPhone Safari의 가상 키보드/IME와 운영 릴레이 송수신은 별도 실기기 검증이 필요하다.

## 제작 게임 검토

퍼즐 방식은 유지한다. 골조·전기·한지·채색의 결과가 미리보기에 반영되는 현재 구조를 쓰되, 손과 재료가 실제로 움직이는 조립 애니메이션은 이번 변경에 포함하지 않았다.
