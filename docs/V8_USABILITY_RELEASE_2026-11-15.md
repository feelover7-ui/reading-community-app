# V8 PC·모바일 사용성 개선

사용자가 PC·모바일 검토안 전체 구현과 운영 배포를 승인했다. 기준 main은 fbe8da5이며 PR35는 이미 병합된 상태다. 기존 배치·캐릭터·통신 계약과 v8 밖의 앱은 변경하지 않는다.

## 변경 범위

- 참배 중 지도 이동/일시 정지/재시작을 명시적으로 처리하고 탑돌이 체크포인트를 보존한다. 늦은 탑돌이·삼배 콜백은 취소 토큰으로 차단한다. 하나의 안내 영역에서 진행과 재개 행동을 제공한다.
- 지도에는 아홉 장소의 활동을 표시한다. 지도는 오른쪽 버튼/M키, 설정은 PC 톱니바퀴/모바일 메뉴로 통일한다. 접속자·방명록은 아래에서 접근한다. 모바일 가로 화면은 인사·대화 버튼을 오른쪽 아래 가로줄에 둔다.
- 제작 화면은 PC768px 높이에서도 작업판·진행 결과가 함께 보이도록 조정한다. 모양별 도안, 재료 부착 피드백, 진행을 대신 풀지 않는 전기 힌트를 제공한다.
- 자동 탑돌이는 탑과 걷는 경로를 함께 담는다. 수동 시점과 일반 걷기는 유지한다. 장소 이름표는 가까운 것과 현재 행동을 우선하며 겹침을 줄인다.
- 주요 안내의 글자 크기·대비를 높인다. 운영 채팅/방명록/등 공유 쓰기는 검증 과정에서 차단한다.

## 검증 기록

구현 전 전체 Node367개 통과. 최종 전체 Node398개 통과, npm run build 및 diff 검사 통과. 기존 Three.js 큰 번들 경고는 남아 있다. 독립 코드 검토에서 찾은 채색 영역·참배 UI 겹침·지속 대화의 가로 화면 잘림을 수정하고 재검토 승인을 받았다.

- `scripts/qa-v8-usability.cjs`: PC1366×768, 모바일390×844·375×667·844×390 지도 선택/단축키/버튼 히트테스트/설정 진입.
- `scripts/qa-v8-mobile-craft.cjs`: 실제 클릭·터치로 전 공정, 실패 후 복구, 저장·재개, 미전시 완성품.
- `scripts/qa-v8-craft-shapes.cjs`: 모양별 실제 작업 영역과 라벨 클릭.
- 참배 취소·재개와 카메라 수학은 해당 Node 회귀 및 브라우저 검증으로 확인한다.

실제 iPhone Safari 키보드·GPU 성능, 운영 DB 쓰기·릴레이 부하는 이 자동 Chromium 검증과 구분한다. 제작 피드백은 가벼운 도안/재료 애니메이션이며 사실적인 손 모델 애니메이션을 뜻하지 않는다.

## 작업 중 추가 요청

대화 글의 시간 만료를 없애고 접속 안내를 추가한다. 입력창은 전송 뒤 닫히며 최근 표시 개수/접속 중 기록 상한을 유지한다. 실명 인증은 확인 수단/업체 결정이 필요하여 구현 범위를 별도로 확인 중이며, 입력한 닉네임을 인증된 이름으로 표시하지 않는다.

사용자가 명부 대조·관리자 승인 방식을 선택한 뒤 실명제를 보류했다. 후속 작업은 docs/V8_TODO.md에 기록했다. 이번 배포에서는 실명 인증/출석 검증을 주장하지 않는다.

- 지도/메뉴: PC1366×768, 모바일390×844·375×667·844×390 전부 장소별 설명, 핀 히트테스트, 실제 이동, PC M/방향키/Enter, 설정 진입 통과.
- 제작: 실제 다섯 공정 ×1366×768·390×844·375×667·844×390·375×560 모두 본문 overflow0 및 작업 버튼44px 이상 확인. 375×667 전 공정 실제 터치·잘못 연결하기·힌트의 저장 무변경·한지 저장/재개·pendingHang 완료 통과. 여섯 도안 PC/모바일 실제 채색 통과. 최종 PC 전체 완료를 별도로 반복하지 않았으며 기존 단계별 상호작용 및 최종 화면 배치 검증을 조합했다.

- 채팅: PC/모바일 실제 앱에서9.5초 뒤 유지, 입력/한글 조합/실패 초안/기록60개/키보드 화면, 로컬 BroadcastChannel 접속 안내 중복 방지 및 안전한 문자열 표시 통과. 짧은 가로 화면의 긴 대화 최근5개/3개 표시도 확인. 자세한 기록은 V8_CHAT_ATTENDANCE_2026-11-15.md.
