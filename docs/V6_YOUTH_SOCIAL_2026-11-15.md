# v6 캐릭터 및 접속 안내

사용자가 앞으로 v6를 수정하며 앞서 제공한 남녀 캐릭터 시안을 적용하도록 요청했다.
진행 중 대화 표시 유지 여부, 출석 안내, 실명 확인 방식을 추가로 물었다.

## 구현

- 두 원본 시안을 참조해 투명 PNG 스프라이트를 새로 생성했다. 남성은 세이지색 겉옷,
  여성은 로즈색 상의와 바지이며 둘 다 가방이 없다. 자연스러운 청년 비율을 유지한다.
- `public/v6/youth-atlas.png`는 3개 자세 × 6개 방향/성별 행이다. `src/v6/character.js`에서
  정면·후면·좌우, 정지·걷기 프레임을 그린다. 프레임의 발 기준점과 크기를 고정한다.
  새 모습은 자신의 캐릭터와 다른 접속자에게 적용한다. 기존 안내 NPC 그림은 유지한다.
- 입장 선택 화면에서 실제 게임 스프라이트를 미리 보여준다. 이름표·소원등·대화 및
  작업 안내를 새 캐릭터 머리 위로 옮긴다. 이미지 로드 실패 시 기존 도형 렌더러로 계속 작동한다.
- 대화 기록에는 만료 시간이 없다. 최근 PC6개·모바일3개를 표시하고 새 항목이 오면 오래된
  항목이 밀린다. 머리 위 말풍선은 기존 6초 표시다. 모바일 가로에서도 기록을 숨기지 않는다.
- 실제 Presence 연결 후 자신의 출석, 최초 명단 동기화 이후의 새 접속을 로컬 안내한다.
  초기 명단·중복 join·재연결에는 반복 안내하지 않는다. 안내는 DB에 쓰거나 재방송하지 않는다.
- 이것은 검증된 출석이나 실명제가 아니다. 실명제는 `V6_TODO.md`에 보류했다.

## 선택과 한계

시안의 얼굴·비율을 유지하려고 단순 도형이나 새 3D 모델 대신 시안 기반 2D 이미지를 사용했다.
원본 그림과 픽셀 단위로 동일하지 않으며, 3D 자유 시점 캐릭터가 아니다. 이동·충돌·작업장
지도·제작 순서·다른 버전 파일은 변경하지 않는다. v7·v9는 클로드 영역이다.

## 검증

- `tests/v6-arrival.test.mjs`: 최초 명단/재접속 중복 방지, 대화 만료 없음, 스프라이트 방향과 프레임.
- `scripts/qa-v6-youth-social.cjs`: PC/모바일/가로 화면, 실제 렌더러, 가상 API를 통한 전송 및
  6.6초 뒤 대화 유지, 출석 중복 방지. 외부 쓰기/WebSocket 차단.
- `scripts/qa-v6-classic.cjs`: 전 제작 과정·등 걸기/점등·저장 복구 회귀 검사.
- 실제 iPhone 하드웨어나 운영 DB 쓰기 시험으로 표현하지 않는다.

결과: v6 단위 테스트6개 통과, 빌드 성공. 제작 회귀 PC/모바일2종 통과.
캐릭터·대화 시험은 PC1366×768, 모바일390×844, 가로844×390에서 모두 통과했고
브라우저 오류0건이었다. 실제 게임 캡처와 방향별 렌더링은 로컬 `outputs/v6-youth/`에 있다.
