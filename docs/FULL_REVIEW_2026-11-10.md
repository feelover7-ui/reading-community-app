## 먼저 확인할 운영 사항

운영 브라우저에서 접속한 WebSocket은 **Supabase**였다. 연결 안내는 “법우들과 연결됐어요.”, 참가자는 1명으로 정상 표시됐다. 이는 Cloudflare의 80인 릴레이가 활성화됐다는 뜻이 아니다. 운영 80명 부하·모바일 80인 렌더 성능·무료 사용량은 검증하지 않았다. 이번 PR은 운영 환경 변수나 서버 배포를 바꾸지 않는다.

## 분야별 결과

- **디자인·배치:** 클로드의 한 세계 동선과 PR #22의 본관·구정탑·동상·칠보탑 상대 배치를 유지했다. 별도 작업장이나 맵 선택을 되살리지 않았다. 본관 날개의 직각, 랜드마크 상대 위치, 탑돌이 여유 폭과 연결길 검사는 통과했다.
- **모바일·사용성:** 390×844 세로 및 844×390 가로에서 화면, 도움말, 모습 선택, 초점 순환을 확인했다. 초기/게임 화면은 데스크톱 크기도 확인했다. 실제 iOS/Android 기기·가상 키보드는 미검증이다.
- **기능·오류:** 시작→모습 선택, 버튼 초점 후 이동, 자동 탑돌이 시작·이동·중단, 법당 입장, 나가기 링크와 문 앞 복귀를 확인했다. 운영 시작 화면 HTTP 오류 및 pageerror 없음. 로컬 확인 흐름에서도 pageerror 없음.
- **탑돌이:** 브라우저에서는 시작·진행·중단을 확인했다. 세 바퀴 계수·역방향·순간이동 거부·막힘/큰 dt 처리는 단위 테스트로 확인했다. 느린 소프트웨어 렌더 환경에서 브라우저 세 바퀴 실시간 완주를 확인했다고 표현하지 않는다.
- **글·대화:** 실제 브라우저에서 API 모듈만 mock해 초안 보존, 전송 대기 중 왕복, 중복 방지, 늦은 성공 응답 후 새 입력 보존을 확인했다. 운영 DB에는 글·소원등을 쓰거나 삭제하지 않았다.
- **성능:** 기존 모바일 픽셀 비율 상한/그림자 제한과 80인 중 가까운 16명만 관절 모델로 쓰는 구조를 확인했다. 나머지는 공유 인스턴스와 화면 밖 제외를 사용한다. Three.js 청크 약 752.5 kB(압축 192.8 kB)의 기존 경고는 남는다. 이번 결과는 실기기 FPS 보장이 아니다.
- **접근성:** axe 자동 검사에서 시작·모습 선택·게임·도움말·대법당, 가로 모습 선택의 검출 오류 0건. Escape 후 게임 초점 복귀, 마지막 선택 버튼에서 Tab→이름 입력 순환 확인. 수동 화면 읽기 프로그램의 전체 탐방 경험까지 검증한 것은 아니다.
- **보안:** 운영 응답의 CSP·nosniff·referrer-policy 정상 확인. 새 HTML을 위한 외부 스크립트/CSP 허용 출처를 늘리지 않았다. 키/운영 환경 파일을 커밋하지 않는다. RLS·초대 인증·비밀번호 서버 보호와 DB 정책 적용을 완료했다고 표현하지 않는다.
