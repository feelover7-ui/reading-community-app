# 삼배 관절·방석 접지 개선

원인: 법당 좌복 윗면은0.23인데 stepPerson이 사람의 루트를0에 두어 신발/발이 좌복에 묻혔다. 기존 팔다리는 한 덩어리로 회전하고 한 배2.4초에 엎드림 정지 구간이 없어 급하게 보였다.

- makePerson에 무릎·발목·팔꿈치 관절을 더하고 외형 높이/다리 전체 길이는 유지한다. 새로운 bowMotion.js가 자세·부드러운 보간·접지 보정·한 배6.4초를 공유한다.
- 합장→무릎 꿇기→엎드리기→잠시 머물기→무릎→일어나 합장의 흐름이다. 중단 버튼은0.8초 동안 서는 자세로 돌아오며 직접 이동은 바로 반응한다. 동작 줄이기에서는 기존처럼 합장 자세를 유지하고 빠른 카운트를 유지한다.
- CUSHION_TOP과 cushionSupportAt을 좌복 렌더/본인/상대의 실제 지면 높이에 공유한다. 팔다리 관절 치수로 신발·무릎/정강이·손·머리의 최소 높이를 계산해 보정한다. 엎드림에서 정강이 접촉과 이마 높이도 검증한다.
- 근거리 상대 관절과 원거리 인스턴스 모두 방석 높이를 반영한다. 기존 미리보기의 terrain 덮어쓰기를 고쳐 보정 높이를 보존하고 같은 동작 속도를 사용한다. 장면 배치·캐릭터 크기·충돌·절 횟수·presence 프로토콜·DB는 유지한다.

검증: 테스트128개, 빌드, git diff --check 통과. 새 테스트는 동작 경계 연속성/멈춤 구간/동작 줄이기, 좌복 높이, 실제 모델101개 동작 표본의 정점이 좌복 아래로 묻히지 않음, 정강이/이마 접촉 높이를 확인한다. 정확한 인체/의례 모션 캡처 재현은 아니다. 기존 Three.js 번들 크기 경고 유지.

독립 검토에서 미리보기의 루트 보정 덮어쓰기와 엎드림 접지 부족을 찾아 수정했다. 발목 관절로 신발 끝만 닿던 문제를 고치고 실제 정점으로 접촉 테스트를 추가했다.
