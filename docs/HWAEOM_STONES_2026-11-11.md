# 동상 뒤 화엄석 표현 보강

공식 안내 https://hanmaum.org/content/one_tour_08 의 one_tour_0801.jpg를 참고해 화엄석 일곱 개의 간격을 좁히고 비정형 꼭대기·약간 기울어진 변·모서리 두께를 표현했다. 각 돌의 중심과 높이·돌출 깊이는 그대로이며, 외곽 폭만 조금 넓혔다. 동상·길·참배 자리·다른 시설은 이동하지 않았다.

기존 벽돌 줄무늬 재질과 중앙의 돌출 고리 하나를 제거했다. 직접 생성한 512×384 색상/요철 텍스처 두 장을 일곱 돌이 공유한다. 거친 석재 입자와 정면 전체에 이어지는 원형/곡선 새김을 표현한다. 문양은 공식 정면 사진의 시각적 근사이며 실측·정밀 복제는 아니다. 확인되지 않은 뒷면에는 문양을 넣지 않았다. 사진 텍스처·새 조명·의존성은 추가하지 않았다.

검증: 기존 테스트113개, 빌드, git diff --check 통과. 기존 Three.js 번들 크기 경고 유지. 독립 코드 검토에서 중요 결함 없음. Chromium PC1200×900/모바일 모형390×844에서 전체 보기·동상 정면 자동 시점·직접 클릭/터치 설명 확인, pageerror0. 실제 iPhone GPU 성능과 현장 실측은 확인하지 못했다.
